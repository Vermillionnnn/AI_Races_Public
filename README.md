# AI 比赛资料

让多个 AI 在同样的规则、同样的时限下完成同一个任务，比结果，也看过程。每场比赛都配有讲解视频，这里放已经办完的比赛的公开资料：发给选手的选手包、正式题目、裁判程序、选手交的代码和工作日志、成绩。

| 目录 | 比赛 |
|---|---|
| [`nonogram/`](nonogram/) | 数织：round-1 速度赛（30 分钟写求解程序）、round-2 出题赛（45 分钟出难题） |

每一轮的目录结构相同：

```
<比赛>/<轮次>/
  player-kit/                选手包，和发给选手的相同（除去了环境细节）
  开场消息.md                通过对话发给选手的消息（开赛、报时、收尾），附我们怎么发的说明
  judge/                     裁判程序和参考程序
  submissions/<选手>/
    code/                    选手交的代码
    worklog.md               选手自己写的工作日志
  results.md                 成绩
  SHA256SUMS                 正式题集的 sha256
```

选手目录按模型名命名。会话的完整记录不公开（太长）；生成正式题的出题器也不公开，以免以后的题被提前见过。
