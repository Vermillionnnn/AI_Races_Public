## 1. 字段名和前端对不上（红字的根源）
你按群文档转述 + game 的结构自己定了字段（`remaining/current/river/kyotaku…`），
但前端要的是 `wall_left/turn/discards/riichi_sticks/rules/hints/events…`。
✅ 现在完全按《接口说明》返回。大部分字段由 `game.get_state` 直接给出，server 只补 `version` 和 `game_id`。

## 2. 启动方式不符合上线要求
前端说明要求 `python3 server.py --port 8000`、默认 8000、只监听 127.0.0.1、`GET /` 返回 index.html。
你默认 5000、用 `PORT` 环境变量、`GET /` 只回一句 JSON、也不支持 `--port`。
✅ 改成 argparse `--port`（默认 8000）、`GET /` 直接回 `frontend/index.html`。

## 3. 单局全局变量 → 多局 game_id
`current_game` 一个全局，开新局就覆盖。前端要求每次 `new_game` 给新 `game_id`、按 id 找局。
✅ 用 `GAMES` 字典按 `game_id` 存房间，action/state/next 校验 id。

## 4. 不用再猜番数
补丁里那张 `YAKU_HAN` 表（宝牌猜 1 番、混一色不分门清…）是因为 yaku 只给役名。
现在 yaku 返回每役真实番数 + 役满倍数，`result` 由 game 直接给，**补丁和猜表都不需要了**。
`server_patch.py` 我留了个兼容入口（转调 server），实际逻辑都在 server.py。

## 5. rules / length / players 没接住
前端会传 `rules`（四个开关）、`length`（东风/半庄）、`players`、`seed`、`wall`。
✅ 都接住并传给 game；`rules` 原样回显这一场实际用的值。
