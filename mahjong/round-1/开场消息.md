# round-1 开场消息

选手包放在选手仓库的 `mahjong/prompt/`，内容就是 [`../player-kit/`](../player-kit/)；选手提交放 `mahjong/submission/round-1/<模型名>/`。

2026-11-22 推到选手仓库（提交信息用故事里的话）。选手包里只有文件，开场消息由设计者直接打在聊天框里。

所有消息都是老师的口吻，不出戏：不说这是比赛、不说有几个 bug。规则要说清的都在开赛消息里（不联网、只看给的东西、原件不动、复制到哪里、交什么、45 分钟从第一次看时间算）。

```

别联网啊，东西我都给你了，其他的别看。学生交上来的那份原样留着别动，你复制一份到 mahjong/submission/round-1/<你的名字>/ 里再改，名字就写你的模型名，只用小写英文、数字和连字符；改好的代码、给每个人的反馈、规则文档都放在那儿，弄完 push 上来。
```

## 开赛：GPT（Codex 云端）

Codex 云环境会拦截所有出站流量（git 直接拉取、推送都返回 403），只能通过 GitHub 连接（connector）访问仓库（同数织）。口述把开头的 git pull 和结尾的 push 换成用 GitHub 连接，仍是老师的口吻：

```
你那边命令行连不上 GitHub（git pull、git push 都会被拦），读仓库和交东西都用 GitHub 连接（connector），访问选手仓库。东西都在 mahjong/prompt/ 里。

社团的学生终于把各自那块交齐了，我拼起来又改了改，好歹是能用。我们想整理一下发到网上，但是打起牌来手感怪怪的，你先找找 bug，45 分钟内发给我，从你第一次看时间开始算。不只是帮我改代码啊，我还得把反馈发给他们每一个人呢。

html 我请一个程序员朋友写好了，写得挺好的，别大改，你看看接口格式适配一下，服务器上怎么启动他说明里也写了。对了，我们还得做一个新手教学，先顺便写下规则文档。还有，大家规则不统一，干脆做成开关，网页以后可以选。

别联网啊（除了用 GitHub 连接读写这个仓库），东西我都给你了，其他的别看。学生交上来的那份原样留着别动，你复制一份到 mahjong/submission/round-1/<你的名字>/ 里再改，名字就写你的模型名，只用小写英文、数字和连字符；改好的代码、给每个人的反馈、规则文档都放在那儿，弄完用 GitHub 连接推上来。
```

## 开赛：用 ZIP 发选手包（没有挂仓库）

把选手包打成 zip（解压出 `prompt/`）随消息附上。和仓库版的区别：不 git pull、提交目录改成 `prompt/` 旁边新建的目录、做完口头告诉老师而不是 push。设计者 2026-11-22 写的版本（“子目录”按建议改成了“prompt 旁边新建一个目录”，避免和学生原件混在一起）：

```
社团的学生终于把各自那块交齐了，我拼起来又改了改，好歹是能用。我们想整理一下发到网上，但是打起牌来手感怪怪的，你先找找 bug，45 分钟内发给我，从你第一次看时间开始算。不只是帮我改代码啊，我还得把反馈发给他们每一个人呢。

html 我请一个程序员朋友写好了，写得挺好的，别大改，你看看接口格式适配一下，服务器上怎么启动他说明里也写了。对了，我们还得做一个新手教学，先顺便写下规则文档。还有，大家规则不统一，干脆做成开关，网页以后可以选。

别联网啊，东西我都给你了，其他的别看。学生交上来的那份原样留着别动，你在 prompt 旁边新建一个目录，复制一份进去再改，目录名就写你的模型名，只用小写英文、数字和连字符；改好的代码、给每个人的反馈、规则文档都放在那儿，弄完和我说。别弄太久我45分钟后还出门呢。
```

ZIP 版在同一个本地目录里轮流跑时，每次开跑前确认上一位选手的目录已经挪走（设计者的习惯是留档后就删）。2026-11-23 Claude 最高档重跑时，它给助手的提示词里写了“不要打开 `prompt/gemini-4-neon/`”，说明它在某个时候看到过这个目录名或者预先防着，目录本身设计者已经删了。

## 过半时（约 22 分钟）

选手还没推送过任何东西时发。只说情况，不教怎么做：

```
过了一半了啊，现在是 ____，还没看到你 push 东西。
```

## 剩 5 分钟时

```
现在是 ____，还有 5 分钟啊，记得 push。
```

## 到点时

```
到点了，手上的收一收 push 上来，别再改了。
```

截止后推送的内容不算；宽限与否由设计者定，记进评委 README。发消息的时机和方式同数织（选手在调用工具时排队、不打断；卡在思考里时剩 5 分钟再打断一次），见数织 round-1 的 [`开场消息.md`](../../nonogram/round-1/开场消息.md)“怎么发”。
