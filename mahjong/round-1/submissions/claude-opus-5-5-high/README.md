学生交上来的原样在 `mahjong/prompt/`，没动过。这里是复制后改好的版本。

## 怎么跑

```
python3 server.py --port 8000
```

浏览器打开 `http://127.0.0.1:8000/`。完全按 `frontend/接口说明.md` 的上线要求：在本目录执行、支持 `--port`（默认 8000）、只听 127.0.0.1、`GET /` 返回页面、只用标准库、不联网、不写文件、每个请求按 `game_id` 分开。


## “手感怪”的主要原因（已修）

按影响大小排：

1. **立直后暗杠（非役牌）就和不了牌**：暗杠没标出来，被当成明杠，门清和立直都没了 → 无役。（250207 / 250118 / 260331 的接口约定）
2. **听牌提示的“剩几张”偏少**：鸣牌、副露被重复扣。（250207）
3. **结算里每个役的番数是猜的**：补丁按役名查表，鸣牌减番、宝牌张数都会错，加起来和总番数对不上。（250118 只给了总番数）
4. **点数显示含本场和供托**（说明要求不含）；**双倍役满只付单倍**。（补丁 / 260409）
5. **河里的牌全显示成“手切”**、**记录栏是空的**、**碰的时候不能选用不用红五**。（补丁 / 250207）
6. **地和不成立**：键名 `chihou` / `chiihou` 拼写不一致。
7. **符数和番数用的拆法不同**，会出现“平和 40 符”。（260331 / 250118）
8. **指定牌山从东 2 局起全错**：发牌从庄家开始、王牌顺序和说明不一样。（250207）
9. **加杠不能抢杠、四杠散了没做**、因为振听或无役和不了的牌不算见逃。（250207 的 TODO）
10. **规则开关、半庄战没接**：前端传了也被忽略。

## 老师的 server_patch.py 的问题（不在学生反馈里，供您参考）

- 役的番数靠 `YAKU_HAN` 表估，鸣牌减番（混一色鸣牌 2 番等）和“宝牌3”这种都会算错，页面上番数加不起来。
- `points` 用的是 `delta`，含本场和供托。
- `game_id` 固定是 `g1`，两个人同时打会串局；不支持 `--port`，默认端口 5000，按上线要求会启动失败。
- `tsumogiri` 永远是 false，`events` 永远是空，`called_tile` 没给，`rules` 没给（所以页面顶上一直有红字）。

## 规则开关和默认值

| 键 | 默认 | 说明 |
|---|---|---|
| `aka_dora` | `true` | 赤宝牌 |
| `kuitan` | `true` | 食断 |
| `kiriage_mangan` | `false` | 切上满贯 |
| `renpu_fu` | `4` | 连风牌雀头符数 |

雀魂、天凤和那本《麻将竞技入门》在这几条上一致的就照它们取默认值；切上满贯只有 M 联赛这类规则用，默认关。详见 `规则说明.md`。

## 还没做的（规则文档第 8 节也写了）

- 流局满贯、包牌、人和。
- 明杠/加杠的杠宝牌应该在打牌后才翻（现在是杠完立刻翻）。
- 国士无双抢暗杠。
- 电脑只会摸切、能和就和（符合任务书），不立直不鸣牌，所以和电脑打大部分局都是流局。教学前最好让它至少会立直、会打不要的字牌。
- 吃牌后如果所有牌都因为食替不能打，现在会放开限制；更严格的做法是一开始就不给这个吃的选项。
