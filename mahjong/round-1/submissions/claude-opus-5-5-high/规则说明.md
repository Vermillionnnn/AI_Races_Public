# 麻将规则说明（新手教学底稿）

本文档写的是**这个程序实际实现的规则**（立直麻将 / 日本麻将），可以直接当新手教学的底稿。标“⚙ 开关”的条目可以在页面顶上选，开局时传给后端，整场有效。

---

## 1. 牌

一共 136 张：

| 种类 | 写法 | 张数 |
|---|---|---|
| 万子 一万～九万 | `1m`–`9m` | 每种 4 张 |
| 筒子 一筒～九筒 | `1p`–`9p` | 每种 4 张 |
| 索子 一索～九索 | `1s`–`9s` | 每种 4 张 |
| 风牌 东 南 西 北 | `1z`–`4z` | 每种 4 张 |
| 三元牌 白 发 中 | `5z`–`7z` | 每种 4 张 |

- **幺九牌**：1、9 和所有字牌。**中张牌**：2～8。
- **赤宝牌（红五）** ⚙ `aka_dora`（默认：有）：万、筒、索的四张 5 里各有一张是红的（写作 `0m` `0p` `0s`），每张算 1 番宝牌。关掉后全部是普通的 5。

## 2. 一场比赛

- 4 个人，每人开局 **25000 点**。
- **东风战**：东 1～东 4 局；**半庄战**：东 1～东 4、南 1～南 4。（页面上“场数”选。）
- 每局有一个**庄家**。庄家和牌或庄家听牌流局时**连庄**（再当一局庄），否则庄家轮到下家。
- **本场**：连庄或流局时本场 +1；闲家和牌后本场清零。每本场和牌时多拿 300 点（自摸每家多付 100）。
- **结束**：最后一局（东风战东 4、半庄战南 4）打完，如果有人 30000 点以上就结束；没人到 30000 就**延长**（东风战进南场、半庄战进西场），延长中有人到 30000 立即结束，延长 4 局打完一定结束。
  - 最后一局庄家和牌、而且是第一名且 30000 以上，直接结束（和了止め）。
  - 有人点数**低于 0** 立即结束（被飞）。
  - 结束时场上剩的立直棒归第一名。

## 3. 一局怎么打

1. 每人 13 张，庄家先摸一张（14 张）再打一张。
2. 之后按 **庄家 → 下家 → 对家 → 上家** 的顺序：摸一张、打一张。
3. 别人打的牌可以**吃、碰、杠、荣和**（见下）。
4. 牌山摸完（剩下 14 张王牌不摸）还没人和，就是**荒牌流局**。

### 和牌的形状

14 张牌（副露也算在内）组成下面任意一种：

- **4 组面子 + 1 对雀头**。面子是顺子（同花色连着的 3 张，如 `3m4m5m`，字牌不能组顺子）或刻子（3 张一样）。杠子（4 张一样）算一组面子。
- **七对子**：7 种不同的对子（4 张一样不能算两对）。
- **国士无双**：13 种幺九牌各一张，再加其中一种一张。

**和牌还必须至少有 1 番“役”**（见第 6 节）。宝牌不算役：只有宝牌没有役，不能和。

### 鸣牌（吃、碰、杠）

| 操作 | 条件 |
|---|---|
| **吃** | 只能吃**上家**打的牌，和手里两张组成顺子 |
| **碰** | 任何人打的牌，手里有两张一样的 |
| **大明杠** | 任何人打的牌，手里有三张一样的；杠完从岭上摸一张 |
| **暗杠** | 自己手里有四张一样的；不算破门清 |
| **加杠** | 自己碰过的牌再摸到第四张 |

- 同一张牌好几个人要：**荣和 > 碰/杠 > 吃**。两个人同时荣和时都算和（一炮双响），本场和立直棒给按打牌人下家顺序最近的那个。
- 鸣牌（暗杠除外）后就不是**门前清**了，有些役不能做，有些役少 1 番。
- **食替禁止**：吃/碰之后不能马上打出同一种牌（吃的话，筋上另一头也不行，比如用 `4m5m` 吃 `3m` 后不能打 `6m`）。
- 每开一次杠，**翻一张新的宝牌指示牌**（本程序是杠完马上翻）。
- 最后一张牌（河底）不能吃碰杠，只能荣和。

### 立直

门前清（没有鸣牌，暗杠可以）、已经听牌、手里至少 1000 点、牌山还剩 4 张以上时可以**立直**：

- 打出一张横放的牌宣言，宣言牌没人荣和时交 1000 点立直棒放在场上（归下一个和牌的人）。
- 立直后手牌不能再改：摸什么打什么，只能和牌或者在不改变听牌的前提下暗杠。
- 立直本身 1 番；第一巡没人鸣牌时立直是**两立直**（2 番）；立直后一巡之内（中间没人鸣牌）和牌是**一发**（+1 番）。
- 立直和牌可以看**里宝牌**（宝牌指示牌下面那张）。

### 振听

听的牌里有任何一张**在自己的河里**，就是振听：**不能荣和，只能自摸**。另外：

- 别人打出你能和的牌而你没和（包括因为无役和不了），到你下次打牌之前都不能荣和（同巡振听）。
- 立直后漏掉能和的牌，这一局都不能荣和。

### 流局

| 流局 | 说明 |
|---|---|
| 荒牌流局 | 牌摸完。听牌的人从没听牌的人那里一共拿 3000 点（1 人听拿 3000、2 人听各拿 1500、3 人听各拿 1000） |
| 九种九牌 | 自己第一次摸牌时（之前没人鸣牌）手里有 9 种以上幺九牌，可以宣布流局 |
| 四风连打 | 第一巡四个人都打同一种风牌 |
| 四家立直 | 四个人都立直 |
| 四杠散了 | 场上开了 4 个杠，而且不是同一个人开的 |
| 三家和 | 一张牌三个人同时荣和 |

途中流局（荒牌以外）庄家连庄、本场 +1，立直棒留在场上。

## 4. 宝牌

- **宝牌指示牌**的下一张是宝牌：数牌 1→2→…→9→1；风牌 东→南→西→北→东；三元牌 白→发→中→白。
- 和牌时手里（含副露）每有一张宝牌 +1 番；赤宝牌每张 +1 番；立直和牌再看里宝牌。

## 5. 算分 = 符 × 番

### 符（底数）

| 项目 | 符 |
|---|---|
| 底符 | 20 |
| 门前清荣和 | +10 |
| 自摸（平和自摸除外） | +2 |
| 明刻 中张 / 幺九 | 2 / 4 |
| 暗刻 中张 / 幺九 | 4 / 8 |
| 明杠 中张 / 幺九 | 8 / 16 |
| 暗杠 中张 / 幺九 | 16 / 32 |
| 雀头是三元牌、场风或自风 | 2 |
| 雀头是**连风牌**（场风 = 自风） ⚙ `renpu_fu` | **4**（默认）或 2 |
| 听牌形：嵌张、边张、单骑 | 2 |

- 加完后个位进到 10。
- 特例：**平和**自摸 20 符、荣和 30 符；**七对子**固定 25 符；鸣牌后一个符都没有时算 30 符。
- 荣和时用别人那张凑成的刻子算明刻。

### 番 → 点数

- 基本点 = 符 × 2^(番 + 2)。
- 闲家荣和拿 基本点 × 4，庄家荣和拿 × 6（个位进到 100）。自摸时：闲家自摸庄家付 ×2、闲家各付 ×1；庄家自摸每家付 ×2。
- 封顶：

| 番 | 名称 | 闲家 | 庄家 |
|---|---|---|---|
| 5 番，或基本点 ≥ 2000（如 4 番 40 符、3 番 70 符） | 满贯 | 8000 | 12000 |
| 6–7 | 跳满 | 12000 | 18000 |
| 8–10 | 倍满 | 16000 | 24000 |
| 11–12 | 三倍满 | 24000 | 36000 |
| 13 以上（累计役满） | 役满 | 32000 | 48000 |

- **切上满贯** ⚙ `kiriage_mangan`（默认：无）：打开后 4 番 30 符、3 番 60 符也算满贯（不开时闲家荣和 7700、庄家荣和 11600）。
- 役满牌型可以叠加：双倍役满（四暗刻单骑、国士无双十三面、纯正九莲宝灯、大四喜）和几个役满复合时，点数按倍数乘。

## 6. 役一览

“门清限定”的役鸣牌后不能做；“鸣牌 −1”表示鸣牌后少 1 番。

### 1 番
| 役 | 说明 | 条件 |
|---|---|---|
| 立直 | 见上 | 门清限定 |
| 一发 | 立直后一巡内和牌 | 门清限定 |
| 门前清自摸和 | 门清自摸 | 门清限定 |
| 平和 | 4 组顺子、雀头不是役牌、两面听 | 门清限定 |
| 一杯口 | 两组完全一样的顺子 | 门清限定 |
| 断幺九 | 全是 2～8 的数牌 | ⚙ `kuitan`（默认：有）：关掉后鸣牌不能算断幺九 |
| 役牌 | 白、发、中、场风、自风的刻子（杠），每组 1 番；连风牌刻子 2 番 | |
| 岭上开花 | 杠后摸的岭上牌自摸 | |
| 抢杠 | 荣和别人加杠的那张牌 | |
| 海底摸月 / 河底捞鱼 | 最后一张自摸 / 荣和最后打出的那张 | |

### 2 番
| 役 | 说明 | 鸣牌 |
|---|---|---|
| 两立直 | 第一巡立直 | 门清限定 |
| 七对子 | 7 个不同的对子 | 门清限定 |
| 三色同顺 | 三种花色同样数字的顺子 | −1 |
| 一气通贯 | 同一花色 123、456、789 | −1 |
| 混全带幺九 | 每组面子和雀头都带幺九，有字牌，有顺子 | −1 |
| 对对和 | 4 组都是刻子（杠） | |
| 三暗刻 | 3 组暗刻 | |
| 三色同刻 | 三种花色同样数字的刻子 | |
| 三杠子 | 3 个杠 | |
| 小三元 | 三元牌两组刻子 + 一对雀头 | |
| 混老头 | 全部是幺九牌 | |

### 3 番以上
| 役 | 番 | 说明 |
|---|---|---|
| 纯全带幺九 | 3（鸣牌 2） | 每组都带 1 或 9，没有字牌 |
| 混一色 | 3（鸣牌 2） | 一种花色 + 字牌 |
| 二杯口 | 3 | 两个一杯口（门清限定） |
| 清一色 | 6（鸣牌 5） | 只有一种花色的数牌 |

### 役满
天和（庄家第一次摸牌就和）、地和（闲家第一次摸牌自摸，之前没人鸣牌）、国士无双、四暗刻、大三元、小四喜、字一色、绿一色、清老头、九莲宝灯、四杠子；双倍：国士无双十三面、四暗刻单骑、纯正九莲宝灯、大四喜。

## 7. 规则开关一览

| 键 | 默认 | 可选 | 影响 |
|---|---|---|---|
| `aka_dora` | `true` | `true` / `false` | 有没有红五 |
| `kuitan` | `true` | `true` / `false` | 鸣牌后断幺九算不算役 |
| `kiriage_mangan` | `false` | `true` / `false` | 4 番 30 符、3 番 60 符算不算满贯 |
| `renpu_fu` | `4` | `2` / `4` | 连风牌雀头的符 |

默认值的依据：赤宝牌、食断、连风 4 符是雀魂、天凤和《麻将竞技入门》的共同做法；切上满贯只有 M 联赛等部分规则采用，所以默认关。

## 8. 本程序暂时没做的规则

这些在常见规则里有，但现在**没有实现**，教学时先别讲或注明：

- 流局满贯、包牌（责任支付）、人和。
- 明杠/加杠的杠宝牌在打牌后才翻（现在是杠完立即翻）。
- 国士无双抢暗杠。
- 电脑玩家只会摸什么打什么、能和就和，不吃不碰不立直。
