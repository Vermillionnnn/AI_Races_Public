# 新手教学：5 分钟学会在网页上打一局

> 这是给第一次打开页面的人看的短教程。完整规则见 `规则文档.md`。
> 交互式教学页面还没做；这一版先把“怎么点”和“为什么”写清楚。

## 0. 你要做什么

把手里的 13 张牌凑成：

- **4 组面子**：三张连续的顺子（`2m 3m 4m`）或三张一样的刻子（`7z 7z 7z`）；
- **1 对雀头**：两张一样的牌（`5m 5m`）；
- 再满足至少一种**役**（有名字的牌型），然后和牌。

网页会帮你算能不能和、听什么、多少番；你只需要决定打哪张、吃不吃、碰不碰、立不立直。

## 1. 打开页面

1. 浏览器打开 `http://127.0.0.1:8000/`。
2. 顶部选“东风战”或“半庄战”；新手先选东风战。
3. 规则开关不知道就保持默认：红五开、食断开、切上满贯关、连风 4 符。
4. 点“新游戏”。

页面下方是你的手牌；右边单独隔开的一张是刚摸到的牌。

## 2. 轮到你时

- 手牌下面有蓝线的牌：打掉它之后能听牌。
- 鼠标移到牌上：显示“打这张后听什么、还剩几张”。
- 点一张牌就打出去。
- 如果刚摸的牌和手里的牌一样，点右边那张就是“摸切”（刚摸到就打）。

### 按钮

| 按钮 | 什么时候有 | 点了会怎样 |
|---|---|---|
| 立直 | 门清、听牌、点数 ≥1000 | 交 1000 点，之后只能摸切；和牌多翻里宝牌 |
| 吃 | 上家打出的牌能和你手里的两张组成顺子 | 只能吃上家 |
| 碰 | 别人打出的牌和你手里两张一样 | 碰完要打一张 |
| 明杠 | 别人打出的牌和你手里三张一样 | 杠完摸岭上牌 |
| 暗杠 | 自己手里四张一样 | 杠完摸岭上牌 |
| 加杠 | 已经碰过，又摸到第四张 | 杠完摸岭上牌 |
| 自摸 | 自己摸到和牌 | 结算 |
| 荣和 | 别人打出你能和的牌 | 结算 |
| 跳过 | 可以吃碰杠/荣和但你不要 | 放弃这次机会 |

**优先级**：和牌 > 碰/杠 > 吃。多个人同时能操作时，页面会显示在等谁。

## 3. 第一个练习：做顺子

假设手牌有 `2m 3m`，摸到 `1m` 或 `4m` 就组成 `123m` 或 `234m`。
新手先把字牌（东南西北白发中）和 1/9 这种不好连的牌打掉，留下能连成顺子的牌。

## 4. 第二个练习：做刻子

手里有两张 `7z`，别人打 `7z` 时会出现“碰”按钮。
碰完你有一组 `777z`，再打一张不需要的牌。

## 5. 第三个练习：立直

当手牌只差一张就能和（听牌），并且没有吃碰明杠时：

1. 点“立直”按钮；
2. 点一张牌作为宣言牌；
3. 之后每次摸牌直接打出去（摸切）；
4. 有人打出你听的牌时点“荣和”，或者自己摸到时点“自摸”。

立直后不能改听牌；如果放过一次荣和，会振听，只能自摸。

## 6. 常见错误

- **“我有宝牌为什么不能和？”** 宝牌只是加分，不算役；至少要有立直、断幺九、役牌、平和等一种役。
- **“为什么不能荣和？”** 看提示里的“振听”红字；自己的牌河里有你听的牌，或者你之前放过一次荣和。
- **“为什么吃了不能打刚吃的那张？”** 食替规则；刚吃/碰的牌和它筋上的牌不能马上打。
- **“为什么按钮是灰的？”** 不是你的回合，或者你在等别人先决定吃碰/荣和。
- **“为什么电脑一直不碰？”** 这一版电脑是最简策略：摸什么打什么、不吃不碰、能和就和。

## 7. 以后做交互式教学页面的建议

这一版先交规则文档；如果以后要在网页里做“手把手教学”，可以这样：

1. 用 `new_game` 的 `wall` 参数固定一副教学牌山（例如让玩家起手听牌）。
2. 教学步骤用 `events` 和 `waiting_for` 驱动：
   - 第一步只允许“打一张字牌”；
   - 第二步弹出“碰”的说明；
   - 第三步强制立直，并解释里宝牌。
3. 每一步在页面上加一个半透明提示框，不要改 `index.html` 的渲染逻辑；用 `state` 里的 `legal_actions` 判断玩家有没有按教学做。
4. 教学关用 `players=['human','bot','bot','bot']`，`length='tonpuu'`，`seed` 固定，方便复现。

规则文档里的“役种表”和“符/点数速查”可以直接做成教学页的弹窗内容。
