# 立直麻将规则文档（附新手教学）

> 编程社网页麻将 · 指导老师整理版
> 这份文档按**当前代码实际执行的规则**写，和 `frontend/接口说明.md` 的规则开关一一对应。
> 看不懂日文术语没关系，下面第一次出现都会用中文解释。

## 1. 一句话规则

四个人各拿 13 张牌，轮流摸一张、打一张，把手牌凑成 **4 组面子 + 1 对雀头**，
再满足至少一种“役”（有名字的牌型），就可以和牌。谁先和牌谁赢这一局。

- **面子**：三张连续的顺子（如 `2m 3m 4m`）或三张一样的刻子（如 `7z 7z 7z`）。
- **雀头**：两张一样的牌，也叫将牌、对子。
- 和牌时手里一共 14 张（副露的牌按每组 3 张折算）。

牌面写法跟网页一致：

| 写法 | 含义 |
|---|---|
| `1m`–`9m` | 万子（一万到九万） |
| `1p`–`9p` | 筒子 |
| `1s`–`9s` | 索子 |
| `1z`–`7z` | 字牌：东 南 西 北 白 发 中 |
| `0m` `0p` `0s` | 红五（赤宝牌），普通五写作 `5m` |

座位 `0`–`3` 是固定的物理座位：`0` 是起家，`1` 是 `0` 的下家，依此类推。
当前谁是庄家看状态里的 `round.dealer`，每个人的自风看 `seat_wind`。

## 2. 一局怎么走

1. **配牌**：每人 13 张，庄家先摸第 14 张。
2. **摸打**：从庄家开始，按座位顺序（0→1→2→3）轮流摸一张、打一张。
3. **鸣牌**：别人打出的牌，你可以吃、碰、杠；别人和牌时你也可以荣和。
4. **立直**：门清（没有吃碰明杠）且听牌时，可以宣言立直，之后只能摸切。
5. **和牌**：自摸或荣和，算役、符、番、点数。
6. **流局**：牌山摸完还没人和牌，或者出现九种九牌、四家立直、四风连打、三家和、四杠散了。
7. **换庄**：庄家和牌或听牌流局就连庄，否则庄家轮到下家；本场数、供托按规则处理。

### 2.1 鸣牌（吃、碰、杠）

- **吃**：只能吃上家（你左边那位）打出的牌，用手里的两张和它组成顺子。
- **碰**：任意一家打出的牌，你手里有两张一样的，可以碰成刻子。
- **明杠**：手里有三张一样的，别人打出第四张，可以杠。
- **暗杠**：自己手里摸齐四张一样的，可以暗杠。
- **加杠**：已经碰过的一组，自己又摸到第四张，可以加杠。
- 鸣牌后要马上打一张；吃碰后不能打刚吃/碰的那张，也不能打吃牌后“滑过去”的那张（食替）。

**优先级**：和牌 > 碰/杠 > 吃。多个人同时能和时，按离放铳者近的顺序；本实现允许双响，
三家和按途中流局处理。

### 2.2 立直

- 条件：门清（暗杠不算破门清）、点数 ≥ 1000、牌山还剩至少 4 张、打出一张后听牌。
- 宣言时把 1000 点放到桌上作为**立直棒（供托）**，和牌的人最后拿走。
- 立直后只能摸什么打什么；不能吃碰明杠，暗杠也要保证听牌不变。
- 立直和牌多翻一张**里宝牌指示牌**，里宝牌只对立直和牌的人生效。
- **一发**：立直后一圈内和牌，且中间没有人鸣牌，多 1 番。
- **两立直**：第一巡就立直且之前没人鸣牌，2 番（不是立直 1 番 + 两立直 2 番，只算两立直）。

### 2.3 振听

- **舍张振听**：自己的牌河里出现过自己听的牌，就不能荣和（只能自摸）。
- **同巡振听**：这一巡有人打出你能和的牌，你选择不荣和，到下一次自己摸牌前都不能荣和。
- **立直后见逃**：立直后放过一次荣和，整局都不能再荣和。
- 网页的听牌提示会显示 `振听`，看到红字就别等荣和了。

## 3. 什么样的牌能和

除了牌型，还**必须有至少一种役**。只有宝牌、赤宝牌、里宝牌不算役。

### 3.1 基本牌型

- **一般形**：4 组面子 + 1 对雀头。
- **七对子**：7 个不同的对子（四张一样的不能算两对），2 番。
- **国士无双**：13 种幺九牌（1/9 的数牌 + 全部字牌）各一张，再加其中一张，役满。

### 3.2 役种表

番数按**门清/副露**分别写；没写“副露”的就是门清才成立，或者副露不减番。

| 番 | 役 | 说明 |
|---|---|---|
| 1 | 立直 | 门清听牌宣言 |
| 1 | 一发 | 立直后一圈内和牌 |
| 1 | 门前清自摸和 | 门清状态下自摸 |
| 1 | 平和 | 门清、四组顺子、雀头不是役牌、两面听 |
| 1 | 一杯口 | 门清、两组完全相同的顺子 |
| 1 | 役牌 | 白/发/中、场风、自风的刻子，各 1 番 |
| 1 | 断幺九 | 全部由 2–8 的数牌组成；副露时看“食断”开关 |
| 1 | 岭上开花 | 杠后摸岭上牌自摸 |
| 1 | 海底摸月 | 摸最后一张牌自摸 |
| 1 | 河底捞鱼 | 荣和最后一张打出的牌 |
| 2 | 两立直 | 第一巡立直 |
| 2 | 三色同顺 | 万/筒/索各有一组相同数字的顺子；副露 1 番 |
| 2 | 一气通贯 | 同一花色 123、456、789；副露 1 番 |
| 2 | 混全带幺九 | 每组面子和雀头都含幺九牌，且有字牌；副露 1 番 |
| 2 | 七对子 | 七个对子 |
| 2 | 对对和 | 四组刻子/杠 |
| 2 | 三暗刻 | 三组暗刻（暗杠算暗刻） |
| 2 | 三杠子 | 三组杠 |
| 2 | 三色同刻 | 万/筒/索各有一组相同数字的刻子 |
| 2 | 小三元 | 两组三元牌刻子 + 三元牌雀头 |
| 2 | 混老头 | 全部由幺九牌和字牌组成 |
| 3 | 混一色 | 只有一种数牌 + 字牌；副露 2 番 |
| 3 | 纯全带幺九 | 每组面子和雀头都含幺九牌，没有字牌；副露 2 番 |
| 3 | 二杯口 | 门清、两组一杯口（四组顺子两两相同） |
| 6 | 清一色 | 只有一种数牌，没有字牌；副露 5 番 |
| 役满 | 国士无双 | 13 种幺九各一张 + 一对；十三面听是双倍役满 |
| 役满 | 九莲宝灯 | 同一花色 `1112345678999` + 任意一张；纯正九莲是双倍 |
| 役满 | 四暗刻 | 四组暗刻；单骑听是双倍 |
| 役满 | 大三元 | 白/发/中三组刻子 |
| 役满 | 小四喜 | 三组风牌刻子 + 风牌雀头 |
| 役满 | 大四喜 | 四组风牌刻子，双倍役满 |
| 役满 | 字一色 | 全部由字牌组成 |
| 役满 | 清老头 | 全部由 1/9 数牌组成 |
| 役满 | 绿一色 | 全部由 `2s 3s 4s 6s 8s 6z` 组成 |
| 役满 | 四杠子 | 四组杠 |
| 役满 | 天和 | 庄家配牌即和 |
| 役满 | 地和 | 闲家第一巡自摸且之前没人鸣牌 |

**宝牌**：宝牌指示牌的下一张是宝牌。数牌 9 的下一张是 1；风牌 东南西北循环；
三元牌 白发中循环。每张宝牌 +1 番，但宝牌本身不算役。
**赤宝牌**：红五每张 +1 番；`aka_dora` 关闭时牌山里没有红五。
**里宝牌**：立直和牌时翻开的里宝牌指示牌对应的牌，每张 +1 番。

## 4. 符和点数

### 4.1 符

符是“这手牌有多难”的附加值，和番一起决定点数。当前实现按以下规则算：

- 底符 20 符。
- 门清荣和 +10 符；自摸 +2 符（平和自摸固定 20 符）。
- 刻子/杠：
  - 明刻：中张 2 符，幺九 4 符
  - 暗刻：中张 4 符，幺九 8 符
  - 明杠：中张 8 符，幺九 16 符
  - 暗杠：中张 16 符，幺九 32 符
- 雀头：三元牌 +2，场风 +2，自风 +2；场风和自风相同（连风牌）按开关算 2 或 4 符。
- 听牌形：嵌张 +2、边张 +2、单骑 +2；两面、双碰 0 符。
- 七对子固定 25 符（不进位）。
- 平和荣和 30 符，平和自摸 20 符。
- 副露后没有任何加符时按 30 符。
- 最后个位往上进到 10（25 符除外）。

### 4.2 点数速查

| 番/符 | 子家荣和 | 庄家荣和 | 子家自摸（子/庄） | 庄家自摸（每家） |
|---|---|---|---|---|
| 1 番 30 符 | 1000 | 1500 | 300/500 | 500 |
| 1 番 40 符 | 1300 | 2000 | 400/700 | 700 |
| 2 番 30 符 | 2000 | 2900 | 500/1000 | 1000 |
| 2 番 40 符 | 2600 | 3900 | 700/1300 | 1300 |
| 3 番 30 符 | 3900 | 5800 | 1000/2000 | 2000 |
| 3 番 40 符 | 5200 | 7700 | 1300/2600 | 2600 |
| 4 番 30 符 | 7700 | 11600 | 2000/3900 | 3900 |
| 满贯（5 番或以上） | 8000 | 12000 | 2000/4000 | 4000 |
| 跳满（6–7 番） | 12000 | 18000 | 3000/6000 | 6000 |
| 倍满（8–10 番） | 16000 | 24000 | 4000/8000 | 8000 |
| 三倍满（11–12 番） | 24000 | 36000 | 6000/12000 | 12000 |
| 役满（13 番以上/役满牌型） | 32000 | 48000 | 8000/16000 | 16000 |

- **切上满贯**开关打开时，4 番 30 符和 3 番 60 符按满贯算；关闭时按表算（7700/11600）。
- 累计役满（不是役满牌型，但番数 ≥13）：`yakuman` 字段是 0，点数按役满算，符番照常显示。
- 本场：荣和每本 +300 点（放铳者出）；自摸每本每家 +100 点。
- 供托：每根立直棒 1000 点，和牌者拿走。
- 接口里的 `result.wins[].points` 只写这手牌本身的价值，**不含本场和供托**。

## 5. 流局、连庄和终局

### 5.1 流局

| 原因 | 触发 | 处理 |
|---|---|---|
| 荒牌流局 | 牌山摸完没人胡 | 听牌者从没听牌者那里收点：总 3000 点由听牌者分 |
| 九种九牌 | 第一巡手里有 9 种以上幺九牌，可选择流局 | 本场 +1，庄家连庄 |
| 四家立直 | 四家都立直 | 途中流局，庄家连庄 |
| 四风连打 | 第一巡四家打出同一种风牌 | 途中流局，庄家连庄 |
| 三家和 | 一张牌三家同时荣和 | 途中流局，庄家连庄 |
| 四杠散了 | 四家各开过一次杠 | 途中流局 |

### 5.2 连庄、本场、供托

- 庄家和牌 → 连庄，本场 +1。
- 庄家听牌流局 → 连庄，本场 +1。
- 闲家和牌 / 庄家没听牌流局 → 换庄，本场清零（流局时本场仍 +1）。
- 立直棒留在桌上，下一局继续累积，直到有人和牌拿走。

### 5.3 终局

- `tonpuu`（东风战）：东 4 局结束（庄家连庄会延长）就结束。
- `hanchan`（半庄战）：南 4 局结束（庄家连庄会延长）就结束。
- 有人点数为负（被飞）立即结束。
- 终局时桌上的立直棒给第一名。

## 6. 规则开关

新游戏时由网页顶部的选择框传给后端（也可以直接调接口）：

| 键 | 取值 | 默认 | 作用 |
|---|---|---|---|
| `aka_dora` | true/false | true | 是否有红五；关闭时牌山不出现 `0m 0p 0s` |
| `kuitan` | true/false | true | 食断：副露后断幺九算不算役 |
| `kiriage_mangan` | true/false | false | 切上满贯：4 番 30 符、3 番 60 符是否算满贯 |
| `renpu_fu` | 2/4 | 4 | 连风牌雀头算 2 符还是 4 符 |

- 没传的键用默认值；传了的键整场生效。
- 状态里的 `rules` 会回四个键的实际值，网页中间会显示一行。
- 非法值（比如 `renpu_fu: 3`）会返回 HTTP 400。

## 7. 新手第一局怎么玩

1. 打开网页，先选规则（不知道就保持默认），点“新游戏”。
2. 下方是你的手牌；刚摸到的牌在右边单独隔开。
3. 轮到你时，点一张牌打出。**鼠标移到牌上**会显示打这张后听什么；
   牌下方有蓝线表示“打这张能听牌”。
4. 想吃/碰/杠/荣和时，按钮会出现在手牌下面；不想就点“跳过”。
5. **立直**：点“立直”按钮，再点一张牌作为宣言牌。立直后只能摸切，不能改。
6. **和牌**：出现“自摸”或“荣和”按钮时点它。注意：只有宝牌没有役不能和。
7. 一局结束会弹出结算，点“下一局”；整场结束点“再来一局”。

新手建议：

- 先留对子和连续的牌，先打字牌和 1/9 这种不好连的牌。
- 不要为了宝牌拆掉好牌；宝牌只是加分，不能当役。
- 看到“振听”红字，就不要等别人点炮了，争取自摸。
- 不确定能不能和时，先看结算里的“役”列表；没有役就是不能和。

## 8. 当前实现的边界

这些不是规则文档的“标准答案”，而是这一版代码的实际范围：

- 已支持东风战、半庄战、吃碰杠、立直、一发、里宝牌、双响、九种九牌、四家立直、四风连打、三家和、四杠散了。
- **抢杠（加杠时别人荣和）还没做**：加杠会直接完成，`state.chankan` 目前恒为 false。
- 杠宝牌目前是杠完立即翻开（标准规则里明杠/加杠是打牌后翻）。
- 没有包牌（PAO）、流局满贯、人和、十三不搭等特殊规则。
- 电脑玩家是最简单的“摸什么打什么、不吃不碰、能和就和”；它们不会主动做役。
- 三家和、四杠散了按途中流局处理，不做三家分别结算。

如果以后要补抢杠或包牌，建议先定好 `state` 里的字段，再改 `game.py` 的和牌流程；
`yaku.py` 已经预留了“抢杠”1 番的判断。
