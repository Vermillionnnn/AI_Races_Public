# 给 250207 的反馈（game.py）

先说结论：整局流程的骨架是完整的，摸打、吃碰杠、立直、流局、连庄都写到了，`__main__` 里还自己做了随机对局自测，这点很好。问题主要集中在**接口约定**和**和牌结算的上下文**上，所以拼起来会“能跑但手感怪”。

## 严重问题（会导致牌局直接不对）

1. **牌山顺序和前端说明不一致（最严重）**
   - 你按“庄家开始每家 13 张”发牌：`seat = (oya + k) % 4`。
   - 说明写的是**物理座位**：`wall[0:13]` 座位 0、`wall[13:26]` 座位 1……和谁是庄家无关；`wall[52]` 才是当前庄家的第一摸。
   - 王牌也放错了：你用了 `dead_wall[0:4]` 做岭上、`dead_wall[4+2i]` 做宝牌；说明规定 `wall[122:127]` 宝牌指示牌、`[127:132]` 里宝牌指示牌、`[132:136]` 岭上牌。
   - 结果：测试牌山一传进来，四家拿到的牌全错位，宝牌/岭上也不对。已按说明重写 `start_round`、`_draw(rinshan=True)`、`dora_indicators`、`ura_indicators`。

2. **`calc_score` 的返回格式对不上**
   - `score.py` 实际返回的是 dict（`get/ron_pay/oya_pay/ko_pay`），你的 `_parse_score` 按元组 `(得分, 各付)` 拆。
   - 之前 `server.py` 用 monkeypatch 包了一层才能跑；直接跑 `game.py` 就会把 dict 当元组。已让 `game._parse_score` 同时接受 dict 和元组，并增加 `points`（不含本场/供托）给前端。

3. **暗杠信息没有传给 `fu.py` / `yaku.py`**
   - 你调用 `calc_fu(..., melds_plain(seat, True), ...)` 时没传 `an_gang`，`fu.py` 只能把四张的杠当明杠。
   - 调用 `calc_yaku` 时 state 里也没有 `ankan_indices`，`yaku.py` 会认为暗杠是明杠，直接破坏“门清”判断，平和/门前清自摸/立直都会算错。
   - 已由 `game.py` 统一传 `an_gang` 和 `ankan_indices`。

4. **里宝牌被当成普通宝牌**
   - 你调用 `dora_list(with_ura=self.riichi[seat])`，把里宝牌也放进了 `dora`；`yaku.py` 会把它们全标成“宝牌”，而且 game 从来没给 `state['ura_dora']`。
   - 已改成：`dora` 只传普通宝牌，`state['ura_dora']` 传里宝牌，由 `yaku.py` 单独列“里宝牌”。

## 中等问题（规则手感）

5. **规则开关完全没有接**
   - `Game.__init__` 没有 `rules`/`length` 参数；`make_wall()` 永远放红五；`calc_yaku`/`calc_fu` 也拿不到 `kuitan`、`kiriage_mangan`、`renpu_fu`。
   - 已加 `rules`、`length`，并把四个开关一路传到 `yaku.py`、`fu.py`、`score.py`。
   - `length='tonpuu'/'hanchan'` 也补上了；原来的 `_check_game_over` 是“有人到 30000 才结束/南入延长”，和接口的东风战/半庄战不是一回事。

6. **`state` 缺前端要的字段**
   - `get_state()` 里玩家字段叫 `wind`/`river`，前端要 `seat_wind`/`discards`；没有 `called_tile`、`tsumogiri`、`events`、`waiting_for`、`rules`、`viewer`、`turn`。
   - 手牌里包含刚摸的牌，前端是分开画 `hand` 和 `drawn` 的。
   - 已在新 `server.py` 的适配层统一转换；`game.py` 里补了 `called_tile`、`tsumogiri`，并记录了 `events`。

7. **同巡振听清除时机**
   - 你在 `_discard` 里清 `temp_furiten`；正确时机是**下一次自己摸牌**。如果别人鸣牌、你没摸牌就打出，振听会被提前清掉。
   - 已改为在 `_draw` 里清。

8. **立直宣言牌被荣和**
   - 荣和时没有撤销立直：`riichi[seat]` 还是 true，`calc_yaku` 会多算立直；虽然立直棒没扣。
   - 已加 `_cancel_riichi_on_ron`，荣和宣言牌时撤销立直、双立直、一发和河里的横放标记。

9. **碰的红五选项**
   - `_pick_pon_tiles` 只给一个选项，手里同时有 `5m` 和 `0m` 时前端没法选拿哪两张。
   - 已改成生成所有不重复的 `pon` 选项；吃也做了去重。

10. **暗杠的 `from` 写成了自己**
    - 接口规定暗杠 `from: null`、`called_tile: null`；你写的是 `from: seat`。已改。
