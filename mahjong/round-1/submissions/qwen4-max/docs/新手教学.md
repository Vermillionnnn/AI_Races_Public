# 新手教学 · 第一次打网页麻将

> 完全没打过立直麻将也能看懂。跟着走一遍就会了。配套规则细节见 `规则.md`。

## 0. 一句话目标
把手里的牌凑成 **"4 组 + 1 对"**，并且至少有一个"役"，就能和牌赢点数。

## 1. 认识牌
- **万 / 筒 / 索**：各 1–9，每种 4 张。牌面写作 `3m`(三万)、`7p`(七筒)、`2s`(二索)。
- **字牌**：东 南 西 北 白 发 中，写作 `1z`–`7z`，每种 4 张。
- **红五**：红色的五（`0m/0p/0s`），是宝牌，拿到就赚（可在开局关掉）。
- 幺九牌 = 1、9 和所有字牌；其余叫中张牌。

## 2. 怎么才算"凑好"
14 张牌 = **4 组面子 + 1 个雀头（对子）**。
- 顺子：同花色连续 3 张，如 `3m4m5m`。
- 刻子：3 张一样，如 `7p7p7p`。
- 杠子：4 张一样（算一组，但要"杠"出来）。
- 雀头：2 张一样，如 `东东`。
- 例外牌型：**七对子**（7 个不同对子）、**国士无双**（13 种幺九各一张 + 任意一张幺九成对）。

> 小练习：`1m2m3m 4p5p6p 7s8s9s 2s3s4s 5m5m` 就是 4 顺子 + 1 对，能和！

## 3. 关键概念：役
**光凑好牌型不能和，必须至少有一个"役"。** 役就是"认可的赢法"，比如：
- **立直**：门前（没吃碰）听牌时宣布"我差一张就和"，交 1000 点。最常用。
- **断幺九**：手里没有 1/9/字牌。
- **役牌**：白/发/中、或场风/自风的刻子。
- **平和**：门清、全顺子、雀头不是役牌、两面听。
- **门前清自摸和**：没吃碰、自己摸到和牌。
宝牌（含红五、里宝）**只加番、不算役**——没有役时宝牌再多也不能和。

## 4. 一巡怎么玩
1. 轮到你：**摸一张**（右边单独隔开的那张）→ 从 14 张里**打一张**。
2. 别人打牌时，若你能**吃/碰/杠/和**，会弹出按钮；不要就点"跳过"。
   - 吃：只能吃**上家**打的数牌，凑顺子。
   - 碰：任何人打的牌，你手里有 2 张一样的。
   - 杠：4 张一样（暗杠/加杠/大明杠）。
   - 和：自摸或荣和（别人打出你要的牌）。
3. 电脑会自动走，轮到你会停下等你。

## 5. 听牌与提示（本页面的贴心功能）
- **听牌** = 只差一张就能和。页面下方会显示"听：X×N"（还差哪张、剩几张）。
- 手里 14 张时，**蓝色下划线**的牌表示"打这张就能听牌"，鼠标移上去看听什么。
- **振听**（红字）：你河里已经有你听的牌 → 这巡只能自摸、不能荣和。所以别打自己将来要听的牌！

## 6. 立直怎么做
1. 门清且听牌、点数 ≥1000 时，会出现"立直"按钮。
2. 点"立直"→ 选一张打出（宣言牌，会横放）。
3. 没人荣和就立直成立，交 1000 点；之后只能摸切，和牌时多"立直"役，还可能中里宝。
4. 立直后一巡内和牌 = **一发**，再加 1 番。

## 7. 和牌与算点
- 点"自摸"或"荣和"结算。点数 = 符 × 2^(番+2) 再按亲/子、荣和/自摸换算。
- 番越多越大：满贯 → 跳满 → 倍满 → 三倍满 → 役满。
- **庄家（亲）** 赢/输都约 ×1.5；放铳（打出别人和的牌）的人付荣和点数。
- 结算窗会列出每个役各几番、宝牌几张、符数、点数变化，一目了然。

## 8. 开局怎么选
页面顶部：
- **场数**：东风战（短，4 局）/ 半庄战（长，8 局）。新手先东风战。
- **玩家**：我 + 3 电脑 / 4 人轮流（测试）。
- **规则开关**：赤宝牌、食断、切上满贯、连风雀头。新手用默认即可（都有赤、食断允许、不切上、连风4符）。
点"新游戏"开始。

## 9. 新手三条保命建议
1. **先做役**：最常见是"立直"或"断幺九"。别光顾着凑牌型忘了役。
2. **别乱吃碰**：吃碰会破门清、少很多役，还容易振听。门清立直最稳。
3. **看提示打**：跟着蓝色下划线和"听×N"打，剩得多的听牌更容易和。
