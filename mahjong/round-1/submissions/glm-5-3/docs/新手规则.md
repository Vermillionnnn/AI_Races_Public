# 立直麻将新手规则（网页版入门）

> 编程社麻将项目的新手教学文档。看完这一篇就能在网页上开打了。
> 网页顶上可以选规则开关（赤宝牌 / 食断 / 切上满贯 / 连风雀头符数），默认按最常见的网上规则。

## 1. 目标

四个人轮流摸牌、打牌，最先凑出一副**和牌**的形（详见第 4 节）并至少满足一个**役**（第 6 节）的人赢，从别人那里拿点数。整场打完（东风战 4 局、半庄战 8 局，庄家连庄会加局），点数最高的人是第一名。

## 2. 牌

一共 136 张，三种花色加字牌：

| 写法 | 牌 | 张数 |
|---|---|---|
| `1m`–`9m` | 万子 | 每种 4 张 |
| `1p`–`9p` | 筒子 | 每种 4 张 |
| `1s`–`9s` | 索子 | 每种 4 张 |
| `1z`–`4z` | 东 南 西 北（风牌） | 每种 4 张 |
| `5z`–`7z` | 白 发 中（三元牌） | 每种 4 张 |
| `0m` `0p` `0s` | 红五（赤宝牌），代替一张普通的五 | 每种 1 张 |

- **幺九牌**：1 和 9 的数牌、全部字牌。其余叫中张牌。
- **红五**：就是五，只是长得红。算牌型时和普通五一样，但每张多 1 番（宝牌，见第 7 节）。规则开关可以去掉它。

## 3. 一局怎么开始

1. 每人发 13 张牌（庄家 14 张，先出牌）。
2. 桌上翻开一张**宝牌指示牌**：它**下一张**才是宝牌（`3p` 指示宝牌是 `4p`；`9` 的下一张是 `1`；北的下一张是东）。
3. **庄家（东家）先动**，然后按逆时针（下家→对家→上家）轮流。
4. 每一局的庄家会换，你的**自风**跟着座位变；**场风**是整场的（东场 → 南场 → 西场）。

## 4. 和牌的形

**4 组面子 + 1 对雀头（14 张）**。面子有两种：

- **刻子**：三张一样的牌，如 `5s 5s 5s`。
- **顺子**：同花色连续三张，如 `4m 5m 6m`（字牌不能组顺子）。

雀头就是两张一样的牌。

例：`1m2m3m 4m5m6m 7m8m9m 3p4p5p 9s9s`。

另外两个特殊形（必须门清，不能有副露）：

- **七对子**：七个不同的对子。
- **国士无双**：13 种幺九牌各一张，其中一种有两张。

## 5. 一个回合做什么 / 副露

轮到你：**摸一张 →（可以选择杠、立直、自摸和）→ 打一张**。打掉的牌进自己的牌河，别人可以拿走（鸣牌）：

| 鸣牌 | 条件 | 之后 |
|---|---|---|
| 吃（chi） | 别人打出的牌能和手里两张组成顺子，只有**上家**打的能吃 | 拿来组成一组明顺子，然后打一张 |
| 碰（pon） | 手里有两张一样的 | 组成明刻子，然后打一张 |
| 大明杠 | 手里有三张一样的 | 全拿走，从岭上补摸一张，再打 |

自己回合里还能：

- **暗杠**：手里有四张一样的，扣着摆出来（算门清），补摸一张岭上牌。
- **加杠**：之前碰过一组，又摸到第四张，把它加到碰上（**别人这时候可以抢杠和牌**）。

同一张 discard 有人和牌时和牌优先；碰/杠优先于吃。**鸣过牌（除了暗杠）就不算门清了**，一部分役会失效（第 6 节）。

打牌小规矩：刚吃/碰进来的那张以及它的相邻牌不能马上打回去（食替）；立直之后只能摸什么打什么。

## 6. 役（和牌的条件）

**没役不能和牌！** 常见役（按番数）：

| 役 | 番 | 条件（简版） |
|---|---|---|
| 立直 | 1 | 门清报听后不再换牌（交 1000 点供托） |
| 门前清自摸和 | 1 | 门清 + 自摸 |
| 断幺九 | 1 | 全部牌都不含幺九（副露后是否算看“食断”开关） |
| 役牌（白/发/中/场风/自风） | 每组 1 | 有一组对应牌的刻子 |
| 平和 | 1 | 门清、全顺子、雀头不是役牌、两面听 |
| 一杯口 | 1 | 门清，两组一模一样的顺子 |
| 三色同顺 / 一气通贯 | 2 | 三种花色同样的顺子 / 同花色 1–9 一条龙 |
| 七对子 | 2 | 七个对子（25 符固定） |
| 对对和 / 三暗刻 / 三杠子 / 小三元 | 2 | 各种三组刻子系 |
| 混一色 | 3 | 一种花色 + 字牌 |
| 纯全带幺九 | 3 | 每组面子+雀头都带 1/9 |
| 清一色 | 6 | 只有一种花色 |
| 混全带幺九 / 混老头 / 二杯口 | 2–3 | 其余组合系 |

还有立直附带的：**一发**（立直后一圈内和）、**岭上开花**（杠补摸的牌和）、**海底摸月 / 河底捞鱼**（最后一张）、**抢杠**、**双立直**（第一巡就立直）、**里宝牌**（立直和牌才能翻的额外宝牌）。

**役满**（13 番封顶，如国士无双、四暗刻、大三元、绿一色、天和、地和……）不细讲，遇到了就发。

## 7. 宝牌（加番，不是役）

指示牌的下一张是宝牌，手里每有一张就 +1 番；红五每张 +1 番；立直和牌时翻开**里宝牌指示牌**，里宝同样每张 +1 番。杠一次会多翻一张指示牌。宝牌加的番不会救活一手没役的牌。

## 8. 点数怎么算

番数 × 符数决定基本点。符数粗略记：

- 底 20 符；门清荣和 +10；自摸 +2；
- 面子：明刻 2 / 暗刻 4 / 明杠 8 / 暗杠 16（幺九翻倍）；
- 雀头是三元牌或风牌 +2（连风按开关 2 或 4）；
- 嵌张、边张、单骑听 +2；个位进位到 10；七对子固定 25。

封顶线：满贯（5 番）8000 → 跳满（6–7 番）12000 → 倍满（8–10）16000/24000…→ 三倍满 24000/36000 → **役满 32000（子）/ 48000（庄）**。自摸时庄家付两倍。30 符 4 番、60 符 3 番算不算满贯看“切上满贯”开关（默认不算）。

**振听**（暂时不能荣和，只能自摸）：自己牌河里有过能和的牌；或者这一巡放过一次别人的和牌；立直后放过就是永久振听。

**流局**：牌摸完没人和 → 庄家听牌就连庄，否则下庄；听牌的人向没听的人收 1000–3000。中途也有九种九牌、四风连打、四家立直、四杠散了、三家和等流局。

## 9. 网页上怎么打

1. 顶上选规则、场数（东风/半庄）、玩家数，点**新游戏**。
2. 轮到你时手牌会亮，点一张打出；点**立直**后再点宣言牌。
3. 能吃/碰/杠/和的时候出对应按钮，不要就**跳过**。
4. 手牌下面的**蓝线**：打出这张牌之后能听牌，鼠标移上去看听什么、还剩几张（会自动扣掉场上看得见的牌）。显示**振听**时不能荣和。
5. 右侧**记录**栏是这局的全部动作。一局结束弹出结算：役、番、符、点数变化，点**下一局**继续。
6. 和了显示 `X 符 Y 番`（役满只显示倍数和点数）。

## 10. 新手三句话

1. **先记役再记形**：手里先留一个“能和的形”，同时留一个“役”（断幺九、役牌、立直最容易）。
2. **立直很强**：门清听牌就立直，宝牌里宝全归你，一发岭上也常见。
3. **别贪吃碰**：鸣牌断了一半的役，新手阶段门清立直收益最稳。
