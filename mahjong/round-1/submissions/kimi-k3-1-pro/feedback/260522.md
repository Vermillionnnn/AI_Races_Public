# 给 260522（tenpai.py）的反馈

一般形、七对子、国士无双共用判断，红五归一和按剩余枚数输出都能复用，模块本身很干净。本轮保留核心算法，主要修复了**和你的模块相接时的重复计数**：

- `get_waits` 已会扣 `hand + melds + visible`，所以 game 传 `visible` 时不能再包含自己的手牌/副露。
- 被吃碰杠的牌仍显示在河里，但同一物理牌已进入副露，不能再扣第二次。
- 现在 game 构造可见牌时排除自己的副露（由 tenpai 另算）、跳过已 `called` 的河牌，并加入其他副露和指示牌。
- `discard_hints` 保留红五与普通五两个独立打牌键；听五仍归一成同一牌种并合计剩余枚数。

新增 `test_tenpai.py`，覆盖普通和、七对子、国士、副露听牌剩余数、红五打牌提示；测试通过。

建议你在 docstring 中把 `visible` 精确定义为“除 hand 和 melds 外、尚未计数的其他公开牌”，或者下版改成传带 sources 的可见牌集合，从接口上杜绝重复。剩余枚数为 0 的听牌目前仍保留，这是表示牌型听口，不表示一定还能和到。
