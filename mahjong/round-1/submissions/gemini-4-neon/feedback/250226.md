- 联调时发现 `score.py` 和 `game.py` 返回值对不上，能主动做一层适配把流程先跑通，并且对 `tenpai.py` 做了异常兜底，不让提示模块拖垮主接口。

## 发现的问题与需要改进的地方

（说明：之前群里还没发前端程序员的 `frontend/接口说明.md`，所以大部分字段对不上不是你的错；这次拿到完整说明后，把所有需要对齐的地方和工程改进点一起整理给你：）

### 1. 服务器启动与静态页面托管（上线必选项）
- **未托管前端页面**：`GET /` 原来返回的是 `{"ok": true, "msg": ...}` JSON；按说明必须返回 `frontend/index.html`（HTTP 200，`text/html; charset=utf-8`）。
- **未支持 `--port` 参数与默认端口 8000**：上线命令固定为 `python3 server.py --port 8000`（不带参数默认 `8000`），原代码默认 `5000` 且只读了环境变量 `PORT`。现已用 `argparse` 补齐 `--port` 与 `--host`。

### 2. 前后端 JSON 协议全面对齐（对照 `frontend/接口说明.md`）
- **缺少关键顶层字段**：`version: 1`、`game_id`、`waiting_for`、`rules`（4 项规则开关）、`events`（对局记录，且他人 `draw` 事件须隐藏 `tile` 为 `null`）。
- **字段名与结构差异**：
  - `remaining` → `wall_left`，`current` → `turn`，`seat` → `viewer`；
  - `round` 改为 `{wind, number, honba, riichi_sticks, dealer}`；
  - `players[i]` 改为 `{seat, name, score, seat_wind, riichi, discards, melds, hand_count, hand?}`，其中 `hand` **仅对 `viewer` 提供**、且**不含 `drawn`**，`discards` 包含 `tsumogiri`，`melds` 包含 `called_tile`；
  - `legal_actions` 需将 `chi`/`pon` 合并为 `{type, options: [[...], ...]}`，将杠拆为 `ankan` / `kakan` / `minkan`；
  - `hints` 需改为 `{waits: [{tile, left}], furiten: bool, discards: {tile: [{tile, left}]}}`；
  - `result` 需统一为 `agari`（含 `wins[].yaku: [{name, han}]`、`yakuman`、`points` 不含本场和供托）与 `ryuukyoku`（英文 `reason`）。

### 3. 多局管理、参数转发与健壮性
1. **全局单局 `current_game` 与 `game_id` 缺失**：
   - 服务器需要支持连续开很多局，每次 `POST /api/new_game` 分配新的 `game_id`（如 `g1`、`g2`…），且 `/api/state`、`/api/action`、`/api/next` 都要按 `game_id` 校验，不存在或未开局时应返回 HTTP 400 + `{"error": ...}`（原 `GET /api/state` 会静默自动开一局）。
2. **新游戏与操作参数未透传**：
   - `/api/new_game` 需要支持 `players`（如 4 人轮流操作测试模式）、`length`（`tonpuu`/`hanchan`）、`rules`（规则开关），并按说明固定返回**座位 0** 的视角；
   - `/api/action` 需要透传 `tsumogiri`，并直接支持 `ankan`/`kakan`/`minkan`；
   - 严格校验 `seat` 在 `0..3` 范围内，非法值应返回 HTTP 400（不要静默退回 `DEFAULT_SEAT`）。
3. **移除运行时猴子补丁（`game.calc_score = _compat_calc_score`）**：
   - 在 `server.py` 里动态替换别的模块函数会让 `game.py` 脱离 `server.py` 后直接崩溃，以后遇到模块接口不一致时，优先和对应同学把接口约定统一起来。
4. **并发与端口复用**：
   - 改用 `ThreadingHTTPServer` + `allow_reuse_address = True` + 全局 `threading.Lock`，避免重启端口占用（Address already in use）及并发请求串状态。
