# 麻将项目 Code Review 总结（给指导老师 & 全体同学）

本次对 6 位同学提交的模块及指导老师的临时补丁 `server_patch.py` 进行了逐行排查和联调测试，找出并修复了所有导致“打牌手感怪怪的”、算分异常以及前后端接口对不上的问题。

## 一、核心问题总览（为什么之前打起来“手感怪怪的”）

1. **跨模块对接错位（最严重的几类）**
   - **暗杠信息完全丢失**：`game.py` 调用 `yaku.py` 和 `fu.py` 时都没传暗杠标记（`ankan_indices` / `an_gang`），导致每次暗杠都被当成明杠——门前清直接破掉，立直/一发/门清自摸/里宝牌/三暗刻全部失效，符数也按明杠算错。
   - **手牌与摸牌拆分排序 bug**：`server_patch.py` 用 `hand.remove(drawn)` 拆手牌，摸到和手里一样的牌时会删掉前面那张、把新摸的牌留在最右边，导致手牌顺序错乱。
   - **高点法割裂（番、符各自拆牌）**：`yaku.py` 按最大番拆牌，`fu.py` 独立按最大符拆牌，结果同一手牌可能同时拿到 A 拆法的“平和”和 B 拆法的“嵌张/单骑/自摸 30 符”（出现不可能存在的“平和自摸 30 符”或“平和荣和 40 符”）。
   - **剩余张数重复扣除**：`game.py` 的 `get_visible()` 把“河里已被鸣走的牌”和“鸣牌者的副露”算了两遍，又把自己的副露放进 `visible`，而 `tenpai.py` 再次扣除 `melds`，导致剩余枚数严重偏小；此外 `tenpai.py` 的 `discard_hints()` 未把即将打出的那张牌计入已可见牌，打掉听牌张时会多算 1 张。
   - **地和字段拼写不一致**：`game.py` 传 `'chihou'`，`yaku.py` 读 `'chiihou'`，地和永远触发不了。
   - **里宝牌混进宝牌 & 役番展示错误**：`game.py` 把里宝牌直接拼进 `dora`，没单独传 `ura_dora`；`server_patch.py` 用硬编码字典猜单役番数，把 `"宝牌3"`、`"两立直"`、副露减番役、累计役满全部显示错，且把本场和供托混进了手牌 `points`。
   - **指定牌山顺序与接口说明不符**：`game.py` 的 `wall` 发牌按庄家轮转而非物理座位 0–3，王牌区宝牌/里宝/岭上索引也与 `frontend/接口说明.md` 完全相反。
   - **`score.py` 与 `game.py` 返回值格式不匹配**：一个返回 `dict`、一个按 `tuple` 解包，全靠 `server.py` 猴子补丁兜底；且 `score.py` 漏了“2 番 130+ 符封顶满贯”和“双倍/多倍役满翻倍”。

2. **规则逻辑缺陷与规则不统一**
   - 缺失规则：**抢杠**（含国士抢暗杠）、**四杠散了**、**半庄战（`hanchan`）**、**杠宝牌后翻**、**碰红五双选项**、**摸切（`tsumogiri`）记录**、**对局事件日志（`events`）**。
   - 规则细节 bug：**役なし见逃未触发同巡振听**、**食替无合法弃牌时仍允许吃碰**、**立直后暗杠仅查听牌未查面子构成**、**All Last 和了止め同分未按起家判定 1 位**、**三家和未结算立直棒 / 宣言牌被荣和后仍显示立直状态 / 终局剩余供托未计入 delta**。
   - 4 项平台差异规则已全部做成可配置开关（并在网页顶部加入了选择控件）：`aka_dora`（赤宝牌）、`kuitan`（食断）、`kiriage_mangan`（切上满贯）、`renpu_fu`（连风雀头符数）。

## 二、给指导老师关于 `server_patch.py` 的补充说明

老师临时写的 `server_patch.py` 让项目第一时间跑通了页面，非常实用！整理后的正式版已全部收归 `server.py`（不再需要 `server_patch.py`），原先补丁中存在的几个小问题（供参考）已一并解决：
- `hand.remove(drawn)` 导致手牌乱序 → 已改为 `game.py` 内部将 `hands[seat]` 与 `drawn` 分离保存。
- `YAKU_HAN` 静态表估番不准（如 `宝牌3` 被估成 1 番、`两立直` 写成了 `双立直`、副露减番役未减 1） → 已由 `yaku.py` 直接输出精确的 `[{name, han}]`。
- `yakuman = han // 13` 把累计役满误判成真役满 → 已区分真役满倍数与累计役满（`yakuman: 0`）。
- `points` 误用了含本场和供托的 `delta[seat]` → 已改为手牌本身点值 `base_points`。
- 补充了 `rules`、`events`、`tsumogiri`、`called_tile`、多局 `game_id` 管理与 `--port` 启动参数。
