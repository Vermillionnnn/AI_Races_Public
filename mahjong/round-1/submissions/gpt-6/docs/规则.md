# 社团立直麻将入门

点「新游戏」即可开始。第一次玩可以选「我 + 3 个电脑」和「东风战」。电脑会摸切，遇到合法的自摸或荣和会和牌。想与同学一起练习，可以用「4 人轮流操作」在同一张桌上轮换视角。

## 先打一巡

1. 四家各发 13 张，庄家先摸第 14 张。开局每家 25,000 点，座位 0 是起家。之后按座位 0 → 1 → 2 → 3 → 0 的顺序轮转，鸣牌时可以改变轮转顺序。
2. 轮到自己时摸一张、打一张。网页把刚摸的牌稍微隔开。打出它叫**摸切**，从原来的手牌里打叫**手切**。手里有两张一样的牌，点的位置也会影响牌谱。
3. 牌河里的牌都能看见。有人鸣牌拿走一张时，河里仍会留下半透明的记录。网页只会显示当前视角的手牌。

麻将有万、筒、索三种数牌，每种从一到九。字牌是东南西北和白发中。共 34 种、136 张，每种 4 张。牌例中 `3m` 是三万、`7p` 是七筒、`2s` 是二索，`1z` 到 `7z` 依次是东、南、西、北、白、发、中。红五写作 `0m`、`0p`、`0s`，组牌时和普通五是同一牌种。

## 怎么和牌

- 常见和牌形是 **四组面子加一个对子（雀头）**。面子是同一花色连续三张的顺子（如 `2m 3m 4m`）、三张相同的刻子或四张相同的杠子。字牌能组成对子与刻子，杠子也只占一组面子。
- 特殊和牌形有**七对子**（七种不同的对子，同种四张只算一对）和**国士无双**（十三种幺九牌各一张，再有其中一张作对子）。幺九牌是各花色的一、九以及所有字牌。
- 只差一张成形叫**听牌**。例如 `123m 456p 789s 55z 23s` 听 `1s` 和 `4s`。网页在可听牌的舍牌下画蓝线，悬停可以看进张和估计剩余量。余量会扣掉自己手牌、河、副露及公开指示牌里的已知张数，听五时合计普通五和红五。
- 摸进这张叫**自摸**，靠别人打出的牌和叫**荣和**。有和牌形还要至少有一项**役**。常见的役有门前清自摸和、立直、役牌（例如三张中）和断幺九（整手都用二到八的数牌）。宝牌、赤宝牌和里宝牌只给已经有役的手加番。杠后补牌自摸是岭上开花，最后一张正常摸牌自摸是海底摸月，荣和该巡最后一张舍牌是河底捞鱼。
- **振听会禁止荣和，自摸仍可用。** 自己曾打过当前听牌中的任意一种，就不能荣和当前任何一口，之前被鸣走的舍牌也算。放过一次合法荣和会同巡振听，直到自己下次摸牌。立直后见逃会振听到这一局结束。

## 鸣牌和立直

| 按钮 | 什么时候可以用 | 接下来怎么做 |
|---|---|---|
| 吃 | 上家打出的数牌能和手里两张组成顺子 | 亮出顺子，当场打一张 |
| 碰 | 任一家打出的牌与手里两张同种 | 亮出刻子，当场打一张。有红五时可以选用哪两张 |
| 明杠 | 任一家打出的牌与手里三张同种 | 亮出杠子，补摸岭上牌 |
| 暗杠 | 自己手里凑齐四张同种牌 | 摆出暗杠，保持门前清，补摸岭上牌 |
| 加杠 | 自己手里有已经碰出的刻子的第四张 | 将碰升级为杠，补摸岭上牌。其他家可以抢杠荣和 |

同时应答时，荣和优先，其次碰或明杠，最后吃。同级鸣牌按放牌者下家起的顺序处理。有人可操作时，网页会在等到各家都确认或跳过之后再结算。吃碰后须避开食替，也就是立即打出被鸣的同牌种，或者在两面吃时打出原来另一端能吃的牌。有效的杠会翻开一个新宝牌指示牌，从王牌补摸一张，并把正常牌山缩短一张。暗杠只有国士无双可以抢和。

没吃、碰或明杠过叫**门前清**。门清听牌、至少有 1,000 点且正常牌山还有至少 4 张时，可以选一张牌宣言**立直**，交一根 1,000 点的立直棒。本桌在宣言时显示扣分，若宣言牌被荣和就退回。立直后只能摸切、和牌，或用刚摸到的牌暗杠并保持原有听牌和拆法。无鸣牌打断时，第一巡宣言可以算两立直，立直到下次自己打牌前和牌可以算一发。

## 宝牌、符和点数

中央显示的是**宝牌指示牌**。实际宝牌是下一种，数牌九回到一，风牌东南西北循环，三元牌白发中循环。例如指示牌是四筒时，普通五筒和红五筒都各算一张宝牌，红五筒还另算一番赤宝牌。立直和牌会同时翻开对应的里宝牌指示牌。

**番**来自牌型、和牌条件和宝牌。**符**来自面子、雀头、听牌形以及和法。通常从 20 符起算，门清荣和加 10，自摸加 2，最后向上凑整十。七对子固定 25 符，平和自摸 20 符、荣和 30 符，副露荣和最低 30 符。多种拆法成立时，系统比较各拆法实际能拿到的点数。

| 档位 | 条件 |
|---|---|
| 满贯 | 5 番或基本点达到 2,000。启用切上满贯时另包括 30 符 4 番与 60 符 3 番 |
| 跳满 | 6–7 番 |
| 倍满 | 8–10 番 |
| 三倍满 | 11–12 番 |
| 累计役满 | 普通役加宝牌达到 13 番，按一倍役满点数 |
| 牌型役满 | 大三元等役满牌型。大四喜、四暗刻单骑等按两倍，多个役满可以叠加 |

荣和由放铳家付点，自摸由另三家付点。庄家和牌收入较高，闲家自摸时庄家付得较多。比如闲家 30 符 2 番荣和得 2,000 点，自摸则庄家付 1,000、另两位闲家各付 500。本场每本共加 300 点，自摸时每家多付 100。场上的立直棒归和家。允许一炮双响，两家都获牌值，本场与供托给离放铳者顺位最近的和家。结算牌值和表里的点数增减分别显示。

## 流局、换庄和整场结束

- 正常牌山摸完且无人和是**荒牌流局**。有听牌也有未听牌时，未听牌者共付 3,000 点，听牌者平分。庄家和牌或荒牌流局时听牌会连庄。流局及连庄都增加一本场，闲家和牌后本场归零。
- 本桌的途中流局包括九种九牌、四家立直、四风连打、三家荣和和四杠散了。九种九牌可在无人鸣牌的第一巡自己摸牌后宣告，手里须有至少九种不同的幺九牌。四杠散了指至少两个人合计开四杠，第四杠补摸后仍可和牌，打出的牌也可被荣和。途中流局保留供托，庄家连庄。单人开四杠可继续打。
- 东风战先打东一到东四。东四换庄时没有人到 30,000 点则南入，之后一旦有人到 30,000 点就结束，至迟打完南四换庄。半庄打东场和南场，南四换庄便结束。原定末局庄家和牌且以至少 30,000 点独占排名第一时可以直接结束，同分按起家顺序判名次。出现负分时提前结束，终局剩余立直棒给第一名。
- 本桌用听牌罚符结算荒牌流局，用原始点数排终局名次。流局满贯、包牌和比赛用顺位马属于另外的玩法。

## 开局规则开关

「开局规则」中的选择在点「新游戏」时应用，牌桌中央会显示整场实际采用的设置。

| 选项 | 默认 | 会改变什么 |
|---|---|---|
| 赤宝牌 `aka_dora` | 有 | 每种花色的一张普通五换成红五。有役的和牌每张红五另加一番 |
| 食断 `kuitan` | 有 | 允许有副露的断幺九成立。关闭时门清断幺九仍成立 |
| 切上满贯 `kiriage_mangan` | 无 | 30 符 4 番和 60 符 3 番升为满贯。比如闲家荣和从 7,700 点升到 8,000 点 |
| 连风雀头 `renpu_fu` | 4 符 | 场风和自风相同的风牌对子可选 2 或 4 符。风牌刻子的场风役与自风役仍各算一番 |

## 启动和自测

在交付目录用 Python 3.12 运行，默认端口也是 8000。

```sh
python3 server.py --port 8000
```

本机打开 `http://127.0.0.1:8000/`。部署由反向代理连接这个地址，服务器只监听回环地址。接口及指定牌山格式见 [接口说明](../frontend/接口说明.md)。

```sh
python3 -m unittest discover -s tests -v
```
