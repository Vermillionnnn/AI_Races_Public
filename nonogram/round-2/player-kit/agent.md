# 任务：出难题，难倒数织解题器

这一轮反过来：**我们写了一个数织解题程序（"乌龟"），请你出题，尽可能难倒它。** 45 分钟内交出 120 道数织题，乌龟解得越慢越好。

## 乌龟

选手包里的 `乌龟/solver.py` 就是计分用的解题程序。它是纯 Python、单线程、只用标准库，读题和输出的格式和你上一轮写的程序一样。拿上一轮的正式题测，120 道约 50 秒解完。计分时就用这一份，不会改动。

- **可以阅读**，弄清它怎么解题、在哪种题上吃亏。
- **不能直接运行，也不能导入或照抄它的代码**。
- 要测题目，用下面的 `测速.py`。

你可以自己写任何程序，包括自己的解题器，用来检查唯一解、估计难度。

## 你的题

- 规则和纯文本格式见 `格式.md`。题号不重复，只用字母、数字和连字符。
- 一共 **120 道**。行数、列数都在 1–45 之间，不必是正方形，尺寸可以混着出。
- **每道题都必须只有一个解。** 同时交答案，答案必须满足这道题的全部线索。
- 可以写程序生成（"出题器"），也可以手出，也可以混着来。题目要在交卷前生成好，判分时不再运行你的出题器。

## 计分

1. **先查合法**：核对每道题的答案满足线索，再用我们自己的证明程序证明它只有一个解。证明不设时限；找到第二个解的算不合法，我们的证明程序实在证不完的（跑上一整天还没结果）也算不合法。
2. **不合法的题**：不计入用时，另外扣分：第一道扣 10 秒，第二道再扣 20 秒；**有三道或更多不合法，整份题集按弃权处理，没有成绩**。
3. **计时**：用和 `测速.py` 相同的方式跑乌龟：先发一道热身题（不计时），再发你的全部合法题，限 2 个逻辑处理器。每道题最多算 **10 秒**，到时乌龟放弃这道题。**总用时越长越好**，120 道全部卡到 10 秒就是 1200 秒满分。

## 工具

| 文件 | 内容 |
|---|---|
| `agent.md` | 本文件 |
| `上一轮成绩.md` | 上一轮速度赛的成绩 |
| `格式.md` | 数织规则，题目和答案的纯文本格式 |
| `乌龟/solver.py` | 计分用的解题程序：可以阅读，不能运行、导入或照抄 |
| `检查.py` | 检查格式、题数、题号、尺寸，以及答案是否满足线索。**不检查唯一解**，随便用 |
| `测速.py` | 用计分时同样的方式跑乌龟，**只报 120 道题的总用时**和卡到上限的题数，题数不对会拒绝 |
| `裁判/` | `测速.py` 内部用的裁判，不要打开、阅读或直接运行 |

```
python3 检查.py 题目.txt 答案.txt
python3 测速.py 题目.txt
```

Windows 上把 `python3` 换成 `py -3.13`。

**`测速.py` 整场最多用 3 次**，只用来检查你的题集，不能拿它挑题、改题。一次最长要 20 分钟（每道题最多 10 秒），什么时候用，要自己安排。

唯一解要你自己保证，我们只在判分时证明。

## 运行环境

Windows 11 云电脑：8 个虚拟处理器，16 GB 内存。出题器语言自选，只能用标准库，写成一个源文件。已装的编译器和解释器见仓库根目录的 `AGENTS.md`。

## 信息范围

只读 `AGENTS.md`、选手包和你自己的提交目录，不看仓库里的其他内容、git 历史、其他分支或远端仓库。不联网，不调用其他模型、子代理或现成的求解器、出题器。

## 时间

完成时限 45 分钟，从你第一次查系统时间算起。用系统时间计时，不要凭感觉估计。

- 查时间的命令：PowerShell 用 `Get-Date -Format 'yyyy-MM-dd HH:mm:ss'`，Git Bash 用 `date '+%F %T'`。
- 第一步先查时间，算出截止时间，记进工作日志。之后每完成一个阶段也查一次。工作日志里的每个时间，都照抄查时间命令的实际输出。
- 截止时间以最后一次推送为准，截止后推送的内容不算。题目要在截止前生成好、推上去。
