# round-2 开场消息

round-2 是出题赛：选手出 120 道唯一解的题，尽可能难倒乌龟。选手就是 round-1 的同一批会话，接着上一轮的对话发，选手会带着上一轮的经验进来。

选手包推到选手仓库的 `nonogram/prompt/`（替换掉 round-1 的选手包）。提交放 `nonogram/submission/round-2/<目录名>/`，目录名和 round-1 一样，直接写死在消息里，免得重名。

## 开赛

`____` 填这位选手 round-1 的名次，`<目录名>` 换成它 round-1 的目录名。全部成绩在选手包的 [`上一轮成绩.md`](player-kit/上一轮成绩.md)。

```
上一轮你排第 ____ 名，全部成绩见选手包里的 上一轮成绩.md。

第二轮开始：先 git pull 拉取最新代码，然后读 nonogram/prompt/agent.md（这一轮的新选手包），按里面的要求完成。完成时限 45 分钟，从你第一次查系统时间算起。提交目录是 nonogram/submission/round-2/<目录名>/。
```

在 Codex 云端跑的，照 round-1 的 [`开场消息.md`](../round-1/开场消息.md) 另附 GitHub 连接的说明。选手包里的脚本都自己用 UTF-8 输出，不用再附编码说明。

## 报时和收尾

和 round-1 相同（见 [`../round-1/开场消息.md`](../round-1/开场消息.md)），时间按 45 分钟算：过半约 22 分钟，剩 5 分钟约 40 分钟时。

## 加时赛

正赛交卷后接着发。对手换成 round-1 前五名的程序，选手不知道它们的结构；可以改题，也可以原样提交。

```
加时赛：限时 15 分钟，从你下一次查系统时间算起。这一轮的对手换成上一轮前 5 名选手的程序（gpt-6-2-sol、gpt-6-2-astra、claude-fable-5-2、gpt-6a、claude-opus-5-5），你不知道它们的程序结构，也没法运行它们；测速.py 测的仍然是乌龟。你可以针对它们修改题集，也可以不改，直接提交正赛的题。规则和正赛相同：120 道、每道只有一个解、附答案。把加时赛的题目.txt 和答案.txt 放进提交目录下的 加时赛/ 子目录，不改题就只放一个 README.md 写明"沿用正赛题集"；工作日志接着写。
```
