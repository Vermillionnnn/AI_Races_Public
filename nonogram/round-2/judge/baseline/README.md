# 基准解题器

强度和 JS 原型差不多的解题器，用来给选手一个"自己是快是慢"的参照。算法就是 [`./solver.js`](./solver.js) 的"试填到不动点 + 按试填收益选格的深度优先搜索"，没有专门优化；`main.js` 只是按选手协议读写的外壳：一行行读，读到一道完整的题就解，解完立即输出。

```sh
node main.js < 题目.txt > 输出.txt
```

练习题 24 道（40–45 阶）：参考机器上约 28 秒，全部解对；陪练约 0.1 秒。

交给选手的方式：不编译，原样打包进选手包的 `裁判/baseline/`（去掉说明注释），由裁判程序 `--with-baseline` 在选手自己的机器上运行，对比用时不受机器差异影响。规则禁止选手阅读 `裁判/`，以免看出语言和"试填"做法而被带偏。
