# 加时赛题集

120 道新题，36 种尺寸。活动行之间夹一条全白行，一半题转置。生成时反复尝试替换活动行，让每列至少保留两个黑格和两个可留白的活动位置，再从有唯一解证书的候选中筛选。

从本目录运行以下 PowerShell 命令。第一条只读取交付文件并从公开线索重建答案，第二条从种子重新生成，第三条调用选手包的检查程序。

```powershell
py -3.13 generate.py --verify-only
py -3.13 generate.py --output ./reproduced
py -3.13 ../../../../prompt/检查.py 题目.txt 答案.txt
```

### 唯一性

在左右各补一列全白格。记相邻列的黑格数之差为 `d`。它等于该边界上开始的黑段数减去结束的黑段数。所有正差之和是全盘黑段数的下界。对每道题，行线索给出的黑段总数正好达到这个下界。因此所有黑段都从正差边界起步，在负差边界结束。

检验程序按每行的块长和顺序，从两侧分别求最早及最晚可行起点。每个黑段的两个起点都一致，所有行便已确定。程序再核对全部列线索和答案文件，转置的题交换行列验证。整个检验过程不需要生成种子。

### 难度筛选

自写搜索器只使用行线索和各列需要的黑格数。在一项对照中，搜索器自行选分支格，再沿已知正确的颜色继续，以排除因猜错而回溯的影响。正赛题在这个模式下的猜测次数中位数为 5，加时赛为 35.5，范围为 26 至 70。

另一次搜索不使用答案选择分支，120 道题都达到 2400 个搜索结点的预算。独立的整行枚举也在每题扫描 3000 万个候选行图案的预算内未找到解。这些数据只描述自写程序的搜索量。五个参赛程序的实际用时待裁判测定。
