# claude-opus-5-5 数织求解器

单个 C++ 源文件 `solver.cpp`，只用标准库。

## 编译（PowerShell 中直接执行）

```
g++ -O2 -std=c++20 solver.cpp -o solver.exe
```

或 MSVC：

```
cmd /c '"C:\Program Files (x86)\Microsoft Visual Studio\2022\BuildTools\VC\Auxiliary\Build\vcvars64.bat" && cl /O2 /std:c++20 /EHsc /Fe:solver.exe solver.cpp'
```

## 运行

```
cmd /c "solver.exe < input.txt"
```

裁判自测：`py -3.13 裁判/judge.py --cmd "solver.exe" --with-baseline`

## 算法和优化

- **行求解**：两端各加一个白色哨兵（长度 n+2），做前缀可达 DP：`f[j]` = 前 j 块（每块后跟一个白格）能放进前缀的长度集合，用 64 位掩码表示。
  - 块的合法起点 = “连续 c 格非白”且“紧接一格非黑”；各块长的“连续非白”掩码一次递推预计算。
  - 白格闭包（跨过可白格前进）用加法进位技巧 `x | ((A + (x & A)) ^ A)` 一步完成。
  - 反向同样做一遍（位反转后复用正向代码），合并得到每格“可黑/可白”，只可黑的定黑、只可白的定白，都不行就矛盾。
- **行缓存**：每个线程一张 2^14 项直接映射表，键 = 行号 + 已知黑/白掩码 + 题目代号，试填时命中率约 50%。
- **传播**：行、列各存一份黑/白位掩码，脏行 FIFO 队列迭代到不动点。
- **试填（probing）**：每个未知格分别试黑、试白并传播；一边矛盾就定为另一边；两边都成立则取两边结论的交集。同一轮里已被某次试填推出的“格=值”视为已知一致，跳过这一侧；没有新结论时再做一轮完整试填，保证不动点准确。
- **搜索**：按 (黑侧新增+1)·(白侧新增+1) 选分支格（比 min/和 两种打分都好），先试新增**少**的一边（最少约束值，练习题上猜测次数明显减少），DFS，每层重复试填。
- **校验**：解出后逐行逐列核对线索，不通过就输出 `UNSOLVED`（绝不答错）。
- **并行**：读题线程边读边派发；2 个工作线程各解一道题；队列空时空闲线程用镜像分支顺序协助另一线程正在解的题，先完成者输出（原子标志保证每题只答一次），另一方中止；有新题入队时协助立即退出。每题输出加锁并 flush。

## 自测结果（练习题 24 道，本地 Linux 容器，裁判限定 2 核）

| 版本 | 解对 | 总用时（中位） |
|---|---|---|
| v1 行 DP + 传播 + 试填 + DFS | 24/24 | 241.2 ms（单遍；基准程序 34975.2 ms，145 倍） |
| v2 + 行缓存、试填跳过 | 24/24 | 138.6 ms（--repeat 3） |
| v3 + 空闲线程协助 | 24/24 | 91.9 ms（--repeat 3） |
| v4 + 预计算连续非白掩码 | 24/24 | 88.1 ms（--repeat 3，三遍 101.9/88.1/68.3） |
| v5 交集后只标脏受影响的列 | 24/24 | 81.6 ms（--repeat 3，三遍 78.6/81.6/82.8） |
| 最终版：分支先试新增少的一边 | 24/24 | **48.5 ms**（--repeat 5，五遍 53.7/43.4/51.8/46.5/48.5） |
