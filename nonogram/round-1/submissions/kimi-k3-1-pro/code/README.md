# Nonogram 求解器

单文件 C++20 实现，仅使用标准库。程序持续从标准输入读取题目，每读完整一道就求解，并在每道答案后 `flush`，兼容裁判的热身题／正式题两批发题流程。

## 编译

在提交目录的 PowerShell 中执行：

```powershell
g++ -O2 -std=c++20 main.cpp -o main.exe
```

## 运行

```powershell
cmd /c "main.exe < input.txt"
```

从选手包目录用裁判测试（练习题的输入由裁判自动提供）：

```powershell
$env:PYTHONIOENCODING='utf-8'
py -3.13 裁判/judge.py --cmd "..\submission\round-1\kimi-k3-1-pro\main.exe" --with-baseline
```

## 算法与优化

- 每行、每列使用两个 `uint64_t` 位掩码记录已知黑格和白格；候选长度最大 45，因此无需堆分配的动态位集。
- 单行精确动态规划：计算所有合法前缀 `f[p][k]` 和后缀 `b[p][k]`，联合所有可行块位置，得到每格是否可能为黑／白，再提取必然黑格、必然白格。显式处理块间强制分隔白格。
- 使用行列工作队列传播推导；只重算受影响的线，并同步更新对应的行、列位掩码。
- 对尚未确定的格子做矛盾试填（singleton probe）：若一个取值导致矛盾，就确定另一个取值并继续传播。试填顺序按所在行、列的可行排列数乘积排序，优先处理最受约束的格子。
- 若试填不能继续推进，用动态规划统计每条线的可行排列数，选择排列数最少的线，枚举其完整排列并深度优先回溯。每个分支后重新执行传播和试填；双重矛盾会正确触发回溯。
- 输出前所有格子均已确定；不会猜测性输出未完成答案。诊断计数写到标准错误，不混入标准输出答案。

## 自测结果

环境：Windows 11，g++ 16.2.0，裁判限定 2 个逻辑处理器。

2026-11-18 使用正式裁判流程测试全部 24 道练习题：

- 解对：**24/24**
- 答错：**0**
- 未解：**0**
- 本程序总用时：**5868.5 ms**
- 同机基准总用时：**25613.7 ms**
- 速度：约为基准的 **4.36 倍**

另以 `--repeat 3` 做最终复测，三遍均为 24/24、0 答错；总用时分别为 **5873.4、5852.4、5845.7 ms**，中位数 **5852.4 ms**。

热身题也成功即时回答，验证了分批输入和逐题 flush 流程。
