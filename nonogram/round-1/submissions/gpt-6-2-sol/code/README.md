# GPT-6 数织求解器

## 编译和运行

在仓库根目录的 PowerShell 中运行。使用仓库指定的 MSYS2 UCRT64 g++ 和 C++20，只依赖标准库。

```powershell
g++ -O2 -std=c++20 .\nonogram\submission\round-1\gpt-6\main.cpp -o .\nonogram.exe
cmd /c ".\nonogram.exe < .\nonogram\prompt\练习题.txt"
```

用选手包裁判做三轮对照测试。

```powershell
Push-Location .\nonogram\prompt
py -3.13 .\裁判\judge.py --cmd '../../nonogram.exe' --with-baseline --repeat 3
Pop-Location
```

## 求解方法

- 每行和每列各用两个 64 位掩码表示已知黑白格。单行动态规划用位集表示每段黑格的所有候选起点，结合从左和从右可达的边界，求出每格能否为黑、能否为白。白格间隙的正向可达性用整数加法中的进位计算。
- 仅重新传播发生变化的行列。每个工作线程缓存近期的单行状态和推导结果。试填记录访问过的行列，棋盘推进后可跳过依赖仍有效的试填。
- 传播停滞时，按已知邻居、所属行列的已知格数和之前试填的推导量给未知格排序。优先扫描上一次推导改变的行列，再按需扫描全盘。分别试填黑白，排除矛盾的颜色并采纳两种结果共有的推论。仍无法推进时，优先选择两种颜色都能带来较多推导的格子，用显式栈回溯。
- 两个工作线程消费同一题目队列。深度搜索会定期回到队尾，保留棋盘和回溯状态。每道题输出前重新核对全部行列线索，整段答案写完即刷新。
