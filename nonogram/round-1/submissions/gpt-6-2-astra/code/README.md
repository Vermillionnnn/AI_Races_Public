# GPT-6 Codex 数织求解器

单文件 C++20 程序。每读完一道题就交给两个求解线程之一，每个答案整块写入标准输出并立即刷新。

## 编译与运行

在仓库根目录的 PowerShell 中编译：

```powershell
g++ -O2 -std=c++20 nonogram/submission/round-1/gpt-6-codex/solver.cpp -o nonogram/submission/round-1/gpt-6-codex/solver.exe
```

直接用练习题作标准输入：

```powershell
cmd /c "nonogram\submission\round-1\gpt-6-codex\solver.exe < nonogram\prompt\练习题.txt"
```

用随题裁判复测：

```powershell
Push-Location nonogram/prompt
py -3.13 裁判/judge.py --cmd "../submission/round-1/gpt-6-codex/solver.exe" --repeat 3 --with-baseline
Pop-Location
```

## 算法

- 每行和每列分别保存已知黑格、白格的 64 位掩码。正向动态规划按黑块计算可行起点，反向动态规划计算可行终点。两个方向对齐后，可以求出哪些格子至少能在一种摆法中为黑或为白。单色有支持的格子立即定色。连续跨越白格的可达位置通过整数加法的进位一次算出。
- 行列交替传播，只处理发生变化的线。单线缓存用完整的黑白掩码核对命中；同一行在固定棋盘上反复试填时，另存每个位置两种颜色的推导结果。
- 传播停滞后，对未知格分别试黑、试白。先检查相交的行与列，有进一步推论才复制棋盘。一个假设矛盾就取另一色，两个假设共同推出的格子也能定色。新定色格旁的未知格优先重试。
- 需要分支时，比较试黑和试白各自定色了多少格，优先选择两者中较小值更大的位置。备用棋盘存放在显式回溯栈中。输出前从最终行位图重新计算横纵线索。

## 自测

在本次 Linux 云环境使用 GCC 14.2.0、标准库和两个逻辑处理器测试。正式 Windows 机器上的用时以其裁判为准。

| 裁判三遍 | 第 1 遍 | 第 2 遍 | 第 3 遍 | 中位数 |
| --- | ---: | ---: | ---: | ---: |
| 本程序 | 32.5 ms | 29.8 ms | 31.2 ms | **31.2 ms** |
| 基准程序 | 25551.9 ms | 25495.2 ms | 25873.5 ms | 25551.9 ms |

本程序三遍均解对 24/24，答错、未解和未回答均为 0。另将练习题分别旋转 90°、180° 和 270°，72 份答案均通过独立线索校验；250 道独立生成的小型矩形题也全部通过。在 2×3 网格上穷举了 675 组行列线索，程序正确区分了全部 58 组有解线索和 617 组无解线索。
