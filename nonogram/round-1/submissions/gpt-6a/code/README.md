# gpt-6a：数织求解器

一个 C++20 源文件，仅使用标准库。支持 1–45 行、1–45 列的合法数织输入，覆盖正式比赛的 40–45 阶题目。不内置练习题答案，不联网，不读取其他文件。

## 编译与运行

以下命令从仓库根目录在 PowerShell 中执行，采用根 `AGENTS.md` 的 g++ 编译选项：

```powershell
g++ -O2 -std=c++20 nonogram/submission/round-1/gpt-6a/solver.cpp -o nonogram/submission/round-1/gpt-6a/solver.exe
cmd /c "nonogram\submission\round-1\gpt-6a\solver.exe < nonogram\prompt\练习题.txt"
```

按指定裁判流程自测：

```powershell
Push-Location nonogram/prompt
py -3.13 裁判/judge.py --cmd "../submission/round-1/gpt-6a/solver.exe" --with-baseline --repeat 3
Pop-Location
```

Linux 上也可用同一条 `g++ -O2 -std=c++20` 命令编译，将运行命令改为对应可执行文件路径，裁判解释器改为 `python3`。不需要第三方依赖、平台扩展或额外优化开关。

## 算法与优化

- **精确单行推理**：以 64 位整数保存所有可达边界位置。对每个黑块执行前向和后向 DP，求出所有合法摆放中黑、白两种颜色各自的支持集。右向白格闭包利用无符号减法传播借位，左向闭包使用六次倍增；在行末附加白色哨兵统一处理分隔格。相同长度黑块共用合法起点掩码，已完全确定的行直接核对游程。
- **增量传播**：行、列各存黑白位图，双向保持同步；两个脏行位集只调度受到新结论影响的约束。
- **试填与搜索**：分别试填黑、白并传播。矛盾时确定另一颜色；两种试填共同推出的格子直接加入原盘面。没有新结论时，选择两边推理增益乘积最大的试填结果进行完整 DFS。候选顺序结合行列已知格数与邻接已知格数。
- **缓存**：每个工作线程独享 65536 项、约 2 MiB 的行推理缓存，跨题复用存储空间。缓存比较完整的黑白输入和行标识，哈希碰撞只影响命中率。输入只用低 45 位，高 19 位存行标识；标识回绕时清空，避免跨行或跨题误命中。
- **控制开销**：盘面和候选格使用紧凑结构；共同结论只比较两种试填均改变的行；线索整数直接解析。
- **两线程流水线**：主线程每读完一道题立即入队，两个工作线程取题求解，不等 EOF；已入队题目优先取尺寸较大的题目。每道答案整体加锁输出并立即 flush，允许乱序且不会交错。每次输出前重新逐行、逐列核对全部线索，失败则输出 `UNSOLVED`。
