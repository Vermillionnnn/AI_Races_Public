## 算法

1. **位棋盘**：边长 ≤ 45，每行/列用两个 `uint64_t` 表示（可黑位、可白位），行列掩码同步更新。
2. **精确单行求解（广义弧相容）**：每条线做两次 O(线长 × 块数) 的 DP：
   - 前向 `F[i][j]`：前 i 格已定、前 j 块已放好的状态是否可达；放第 j 块要求覆盖区间内没有已确定的白格，块后强制一格白。
   - 反向 `B[i][j]`：从该状态能否补完到接受态 `(n, k)`。
   - `F[i] & B[i+1]` 判某格可为白；对每个「可达且能补完」的放置区间做差分加，判某格可为黑。
   - 合起来得到这条线上所有合法图案都一致的格，即该线约束下能推出的全部信息。
3. **队列驱动传播**：一行/列更新就把受影响的列/行入队，直到不动点；任一行无解立即判该分支矛盾。
4. **搜索**：DFS + 回溯，逐格分支。
   - 分支线：对所有未完成的线算可行图案数，选最少的那条（约束最强）。
   - 分支格：在该线里用带权前后向 DP 算出每格为黑的图案数，挑概率最接近 1/2 的格，先试概率大的一侧。
   - 回溯时整体还原网格与队列状态。
5. **多线程**：主线程边读边入队，2 个工作线程并行解不同题；输出加锁，`SOLUTION` 整段写出后立即 flush。热身题不等正式题。
6. **自检**：输出前逐行逐列复核网格；不通过就输出 `UNSOLVED`（答错要扣分）。
7. **兜底**：单题节点上限 25 万，超过就放弃该题输出 `UNSOLVED`，不拖住其它题。

## 正确性

- 单行求解器、计数 DP、逐格黑格计数在 20 万组随机小样例上与暴力枚举逐位比对，全部一致。
- 裁判按「网格是否满足全部线索」判对，本程序输出的解在打印前已复核。
