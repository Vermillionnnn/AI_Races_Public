# Nonogram 求解器（qwen4-max）

## 编译命令（PowerShell 可直接复制执行）

```powershell
g++ -O2 -std=c++20 "-Wl,--stack,67108864" solver.cpp -o solver.exe
```

## 运行命令

```powershell
cmd /c "solver.exe < 题目.txt"
```

程序从标准输入逐道读题（读到一道完整题立即开始解，不等 EOF），每解完一道输出 `STATS` 统计行 + `SOLUTION <id>` 网格（或 `UNSOLVED <id>`）并立即 flush。两个工作线程并行解题，输出加锁保证答案连续完整。调试信息只写标准错误。

## 算法与优化

- **单行求解器**：位并行 DP。对长度 n≤63 的行/列，用 uint64 掩码表示状态，前向/后向 DP 各 O(n·k)，一次求出与线索和已知格相容的**所有**补全的交集（强制黑/强制白）。白格游程用倍增平行前缀技巧（1/2/4/8/16/32 位移）O(log n) 传播。该 DP 已通过 20 万组小规模暴力枚举对照和 3 万组 40~45 阶已知解可靠性对照，均 0 错误。
- **约束传播**：脏行队列（环形缓冲 + 去重标志），某行变化只把受影响的垂直行入队。
- **回溯搜索**：传播停滞后选静态松弛度最小的行中的未知格分支，先试黑；状态用 memcpy 保存/恢复。猜测上限 50000，超限输出 UNSOLVED。
- **安全网**：输出前逐行逐列校验网格满足全部线索，不满足则输出 UNSOLVED（规则：答错比不答更糟）。
- **并行**：主线程增量解析 stdin，2 个工作线程解题（比赛限 2 逻辑核），逐题 flush。
