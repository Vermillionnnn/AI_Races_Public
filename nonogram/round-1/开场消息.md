# 比赛时的开场消息

选手包放在选手仓库的 `nonogram/prompt/`，选手提交放 `nonogram/submission/<轮次>/<目录名>/`。

## 开赛

轮次换成本轮的目录名（如 `round-1`）；`<your name>` 原样留着，由选手自己填。

```
先 git pull 拉取最新代码，然后读 nonogram/prompt/agent.md，按里面的要求完成。完成时限 30 分钟，从你第一次查系统时间算起。提交目录是 nonogram/submission/round-1/<your name>/，<your name> 换成你的模型名，只用小写英文、数字和连字符（如 deepseek-v41-flash）。
```

接在开场消息后面一起发（2026-11-18 的 round-1 选手包需要；`裁判/judge.py` 已改为自己用 UTF-8 输出，之后的选手包推上去以后可以不发）：

```
可能会碰到的问题：在 Windows 的 PowerShell 里运行 裁判/judge.py，如果报 UnicodeEncodeError（中文输出编码错误），先执行 $env:PYTHONIOENCODING='utf-8' 再运行。
```

## 开赛：Codex 云端

Codex 云环境会拦截所有出站流量（git 直接拉取、推送都返回 403），只能通过 GitHub 连接（connector）访问仓库。在开赛消息后面接着发：

```
注意：这个云环境会拦截所有出站网络请求（返回 403），git pull 和 git push 都不能直接用。拉取最新代码、读选手包、推送提交，都通过 GitHub 连接（connector）访问选手仓库。
```

## 开赛：用 ZIP 发选手包（没有挂仓库）

选手的环境里没有挂选手仓库时，把选手包打成 zip（解压出 `prompt/` 目录）随消息附上，提交改为上传到 Google Drive。`____` 换成本轮的 Drive 文件夹。agent.md 里和仓库有关的几处（`AGENTS.md`、信息范围、git 推送）在消息里改掉，不改选手包本身。

```
附件 prompt.zip 是选手包，解压后读 prompt/agent.md，按里面的要求完成。完成时限 30 分钟，从你第一次查系统时间算起。

这次没有挂代码仓库，agent.md 里和仓库有关的几处按下面改，其余规则不变：
- 没有 AGENTS.md：用这台机器上已经装好的编译器或解释器，开优化编译；把实际用的编译、运行命令写进 README.md。
- 信息范围：只用选手包和你自己的工作目录。除了往 Google Drive 上传提交，不联网；不打开 裁判/ 里的文件，不调用其他模型、子代理或现成的求解器。
- 交付：不用 git。在 Google Drive 的 ____ 文件夹下新建一个子文件夹，用你的模型名命名（只用小写英文、数字和连字符，如 deepseek-v41-flash），把源代码、README.md、worklog.md 三个文件上传进去。截止时间以最后一次上传为准，截止后上传的不算。
```

## 过半时（约 15 分钟）

选手进度明显落后（比如还没推送过任何东西）时发一条，说明情况，不教怎么做：

```
现在是 ____，已经过了大约一半时间，你还没有推送任何文件。
```

## 剩 5 分钟时

开赛约 25 分钟时发一次报时。只报时，不教选手怎么做：时间规划本身也是要比的能力。

```
现在是 ____，离截止还有大约 5 分钟。
```

## 到点时

截止时间到了还没推送，发这一条收尾（round-1 用的原文）：

```
time is up! only wrap up what you have in hand. And push to your submission location. Only wrap up. no more debug or edit of current file.
```

截止后推送的内容按规则不算；是否宽限、宽限多久由设计者定。

## 怎么发

- **选手在调用工具**（跑命令、读写文件）：消息排队即可，下一次工具调用时送到，不打断。我们的做法是尽量不打断 AI 干活，平时都这样发。
- **选手已经停下（会话空闲）**：直接发，会开始新的一轮。
- **选手长时间没调用工具、卡在思考里**：排队的消息送不进去。过半那条可以不发；剩 5 分钟时再打断一次，把报时发进去。

起因：round-1 有一位选手整整 30 分钟都在思考，没调用工具、一个字没写、什么都没推送，排队的消息一直送不进去。

## 交卷过早时

开赛后不到 20 分钟就交卷，发这一段。空里填剩余分钟数。选手已经停下、会话空闲，直接发就行，不用排队也不用打断。

```
你还有 ____ 分钟。提前交卷没有任何好处，对手是其他强大的 AI，比的是程序在正式题上的总用时。继续优化，截止前再推送一次。
```
