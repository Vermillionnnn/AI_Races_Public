# 乌龟（纯 Python 解题器）

参考程序："语言慢但算法对"。只用 Python 标准库，单文件、单线程，没有 C 扩展、没有 numpy，用来和 C++ 写的朴素深搜比。协议和选手一样（见 [`../../player-kit/格式.md`](../../player-kit/格式.md)）：读完一道就解，解完立即输出并 flush，解不出输出 `UNSOLVED`。

## 算法

1. **单行推理（位并行）。** 每行、每列用两个 Python 整数当位集：已知黑、已知白。行尾补一个虚拟白格。每块的可放起点用移位求（连续 L 格都不是白、块后一格不是黑）；"放完前 j 块后光标在哪"的前向集合和"从这里还能放下其余块"的后向集合，都用 Kogge-Stone 式倍增填充（越过非黑格前进）。前后都能接上的起点按块长展开就是可黑格；块后分隔格，加上某一层前向光标 p 和后向光标 p+1 同时可达的格，就是可白格。结果按（已知黑, 已知白）逐行缓存。
2. **传播。** 工作队列只重算有格子变化的行列，行、列交替成批处理。
3. **试填。** 传播停住后，对每个未知格分别试黑、试白并传播：一边矛盾就定成另一边；两边都行就取两边共同推出的格。反复到不动点。没推出东西的试填记下它读过的行列状态，这些行列没变就不再重试。
4. **搜索。** 还解不完就选"两色中较弱一边推出格数"最大的格分支（推出格多的一边先试），分支里继续传播 + 试填，矛盾就回溯。
5. 输出前逐行逐列核对全部线索。

## 运行

```sh
python3 solver.py < 题目.txt                  # 需要 Python 3.10 以上（int.bit_count）
python3 solver.py --stats < 题目.txt          # 每道题前加一行 STATS
python3 solver.py --time-limit 60 < 题目.txt  # 单题时限（秒），默认 120，超时输出 UNSOLVED
```

按比赛流程判分（在上一级的 judge 目录里）：

```sh
python3 judge.py --cmd "python3 turtle/solver.py" --puzzles ../puzzles/round-1.txt --repeat 1
```
